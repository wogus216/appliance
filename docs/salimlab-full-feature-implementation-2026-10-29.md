## 단계별 결과

1. **에러코드(1단계)**: 허브 8곳 항목 80개 전부에 행동 카드 70개 또는 「확인된 조치 없음」 안내를 붙였다(SK매직 10·쿠쿠 7·로보락 10·삼성 4·하이얼 1·귀뚜라미 25·경동나비엔 13). 가스·누수·과열·전기 위험은 사용 중지·연락 카드이고, 점화 실패 3건과 9C2·TC5만 원문이 허용한 확인 단계를 둔다. SK매직 정수기 F:01, 로보락 S7 Error 4, 쿠쿠 E2 적용 모델을 더했다. 없앤 오류 허브 4개(코웨이·다이슨·위닉스·샤오미)는 브랜드 페이지로 301.
2. **도구 페이지(2단계)**: `/tools` 모음, 도구마다 자바스크립트 없이 읽히는 설명 절(자료·계산식·입력 규칙·예시값·오해·원문).
3. **설치 확인(3단계)**: `/tools/install-check` 한 페이지에서 세탁기·건조기 3, 정수기 3, 벽걸이 에어컨 5, 로봇청소기 스테이션 4개 모델. 확인된 여유만 기준에 더하고, 원문 안에서 값이 엇갈리면 계산에 쓰지 않는다.
4. **전기(4단계)**: 공단 신고값을 에어컨·정수기로 넓혔다. 비교는 같은 품목·항목·정격 용량 10% 이내(살림랩 기준, 공단 기준 아님)만 — 에어컨 CTH06QBW↔TAC-08CSD 한 쌍이 늘었다. 전력 기록 여러 개 저장, 한전 주택용 저압 요금 차이 계산(한전 계산기 6사례와 원 단위 일치).
5. **비용(5단계)**: `/tools/water-purifier-cost` 코웨이·LG 정수기 렌탈·구매 합계와 약관 산식 위약금. 확인 못 한 비용은 부분 합계로 분리, 가격 확인 90일 뒤 재확인 경고.
6. **가전 수첩(6단계)**: 관리 목록에 구입일·보증서 날짜·수리 기록, JSON 내보내기·불러오기. 품질보증 종료일은 「소비자기본법 시행령」 별표 1 4호 라·마목의 기산점대로, 부품보유기간은 제조일 기산이라 명판 제조일을 넣을 때만 계산.
