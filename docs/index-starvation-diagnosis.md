(구글은 같은 user-agent 그룹을 병합하므로 동작에는 영향 없음).

## 남는 설명

기술 점검이 전부 통과했으므로 원인은 사이트 신뢰도 쪽이다. 확인 가능한 사실은 둘이다.

**1. 도메인이 34일 됐다.** salimlab.kr 등록일 **2026-08-01**. 대조군 allrunabout.com은 2026-01-18
등록으로 229일이고, 773/931 색인에 30일 노출 84,533·클릭 3,709다. 같은 방법으로 만든 사이트인데
결과가 갈리는 가장 큰 차이가 나이다.

**2. 외부 링크가 없다.** 같은 사람이 운영하는 두 사이트끼리도 서로 링크가 없다(홈 기준 0건).
구글이 이 도메인을 알게 된 경로가 사이트맵 하나뿐이라는 뜻이다.

**추정:** "Crawled - currently not indexed"는 구글이 이유를 공개하지 않는 상태다. 위 둘이
지배 변수라는 것은 대조군과의 비교에 근거한 추정이며, 구글이 확인해 준 사실이 아니다.

## 진짜 병목은 색인 공급량이다

색인 게이트(`src/lib/content-quality.ts`)를 카탈로그 전수에 돌린 결과:

| 단계 | 수 |
| --- | ---: |
| 카탈로그 제품 | 74 |
| 공개(페이지 생성) | 33 — 41개는 `UNVERIFIED_SLUGS`로 404 |
| 그중 **색인 가능** | **14** — 19개는 `noindex` |

`noindex` 19개를 막고 있는 조건은 두 가지뿐이다:

| 막는 조건 | 건수 | 해제 방법 |
| --- | ---: | --- |
| 출처만 부족 (발행처 2곳 미달) | 9 | 서로 다른 발행처 출처 **1건씩** 추가 |
| 사진만 없음 | 8 | 제품 사진 1장 (쿠팡 파트너스 이미지 대기 중) |
| 출처 + 기타 | 1 | `samsung-bespoke-jetbot-ai` |
| 출처 + 사진 | 1 | `qcy-melobuds-pro` |

출처만 부족한 9개는 **가장 싼 복구 대상**이다. 각 제품에 출처 1건씩만 붙이면 색인 가능
제품이 14 → 23이 된다. 페이지를 새로 쓰지 않고 늘릴 수 있는 유일한 구간이다.
