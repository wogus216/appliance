# 냉장고 가상 공간: 이번 단계와 사진·3D에 필요한 자료 — 2026-10-29

[가상 공간 기획](virtual-appliance-room-feature-brief-2026-10-26.md)의 1~3단계(예시 주방 + 2D 평면도, 우리 집 치수 입력, 전기 사용량 연결)를 `/tools/fridge-fit`에서 한 화면으로 묶었다. 4단계(사진·3D)는 아래 자료가 없어 구현하지 않았다. 이 문서는 무엇을 그렸고 무엇을 그리지 않았는지, 다음 단계의 진입 조건을 적는다.

## 이번에 구현한 것

평면도는 설명서 치수와 입력 공간을 같은 축척으로 겹친다. 번호 표식과 아래 목록이 같은 값을 가리키고, 각 값에 종류 표시(공식 자료·사용자 실측·예시값·계산값)를 붙였다.

| 표식 | 그리는 것 | 값의 종류 | 근거 |
| --- | --- | --- | --- |
| ① | 닫힌 본체, 뒷벽에서 최소 후면 간격만큼 띄운 위치 | 공식 자료 | 모델별 설명서 치수표·후면 간격 |
| ② | 문 개방 깊이 끝(뒷벽 기준) | 계산값 = 후면 간격 + 설명서 개방 깊이 | 삼성은 90° 개방 시 문 앞끝, LG는 문을 여는 궤적에서 가장 앞으로 나오는 지점(10-29 도면 재판독) |
| ③ | 문 개방 폭 | 공식 자료 | 삼성 RF85 최대 125°, RS84 최대 165°/170°, LG 최대 개방 도면의 전체 폭(각도 숫자 없음) |
| ④ | 맞은편 가구·장애물 띠 | 사용자 실측 또는 예시값 | 입력 |
| ⑤ | 문 구역 확보 폭(문 앞 좌우 장애물) | 사용자 실측 또는 예시값 | 입력 |
| ⑥ | 냉장고 자리 폭 | 사용자 실측 또는 예시값 | 입력, 본체 + 설명서 좌우 참고 간격과 비교 |
| ⑦ | 맞은편까지 남는 거리: 닫힌 본체 앞면부터, 문 개방 끝부터 | 계산값 | ④ − 후면 간격 − 본체 깊이 / ④ − ② |

- ④가 ②보다 가까우면 둘 사이를 빨간 칸으로 칠해 **문 개방 범위와 가구가 겹치는 길이**를 보여 준다. 사람이 서거나 지나갈 폭의 기준은 정하지 않고 숫자만 준다.
- 예시값은 호박색 점선, 실측값은 초록 실선으로 그려 색을 구별하기 어려워도 모양으로 구별된다. 예시 주방 두 개와 우리 집 실측값은 **따로 보관**한다. 예시를 둘러보거나 예시 값을 고쳐도 실측값은 바뀌지 않는다(이전 구현은 예시를 고르면 실측값을 지웠다).
- 같은 입력으로 네 모델의 자리 폭·높이·문 구역 폭·뒷벽~장애물 차이와 공단 월간 신고 전력량을 한 표로 비교하고, 모델명을 누르면 그 모델의 평면도로 바뀐다. 차이가 +여도 설치 가능 판정을 하지 않는다.
- 복사·파일 저장·인쇄 기록에 각 줄의 값 종류를 붙였다. 예시 장면의 기록에는 `[예시값]`만, 실측 장면에는 `[사용자 실측]`만 나온다.

## 그리지 않은 것과 그 이유

| 표현 | 빠진 자료 | 지금 쓰면 생기는 문제 |
| --- | --- | --- |
| 문이 움직이는 궤적(호) | 문짝별 폭, 경첩 축 위치, 문 두께, 각 문의 최대 각도. 설명서에는 개방 폭·깊이의 바깥 치수만 있다. | 호의 반지름과 중심을 지어내야 한다. 4도어의 위·아래 문 폭이 다르면 궤적도 다르다. |
| 폭과 깊이를 합친 문 개방 직사각형 | 삼성은 폭(최대 각도)과 깊이(90°)가 다른 각도의 도면이다. | 같은 각도에서 동시에 차지하는 범위처럼 보여 실제보다 넓거나 좁게 판단한다. |
| 좌우 벽이 붙은 상태의 개방 제한 | 벽과 경첩 사이 최소 거리, 벽에 붙였을 때 열리는 최대 각도 | 벽 옆 설치에서 문이 90°만 열려도 서랍이 빠지는지 알 수 없다. 설명서 확인 전에는 상담 항목으로 남긴다. |
| 반입 회전·문 분리 후 통과 | 문 분리 후 치수(LG는 확인 못 함), 대각선 길이, 복도 꺾임 치수 | 반입 가능 판정이 된다. 지금처럼 경로 폭만 기록한다. |
| 사진 합성 | 사용자 사진의 축척 기준(기준 물체 크기), 렌즈 왜곡 보정, 제품 정면 이미지 사용 조건 | 화면 속 크기를 실제 크기로 오해한다. 합성 결과로 설치를 판정하게 된다. |
| 3D 배치 | 크기가 검증된 3D 모델(본체·문짝·손잡이), 상부장 높이·깊이, 바닥 수평 | 2D보다 정확해 보이지만 검증된 부분은 같다. 정밀해 보이는 착시만 늘어난다. |

## 2026-10-29 문짝 도면 재판독 결과

네 모델 설명서의 치수·개방 도면을 최대 1200dpi로 다시 보고 텍스트 층의 mm·°·cm 표기를 쪽별로 전수 추출했다. **네 모델 모두 문짝 폭·경첩 축 위치·문 두께가 수치로 없다.** 아래 1번의 ±10mm 검산을 할 수 없어 문 궤적은 그리지 않는다(`research/evidence/2026-10-29/fridge-doors/`). "개방 깊이 − 본체 깊이"를 문짝 폭으로 쓰지 않는다. 목표값에서 거꾸로 뺀 값이라 검산이 아니다.

- LG T873·S834의 개방 깊이(G·F)는 최대로 연 문의 끝이 아니라 **여는 도중 가장 앞으로 나오는 지점**이다. 화면 표기를 그렇게 고쳤다. 값은 그대로다.
- 깊이 기준점이 다르다. 삼성은 본체 뒷면 기준(후면 돌기는 그 뒤), LG는 후면 돌출부 뒤끝 기준이다. 후면 간격도 각 설명서의 기준점에서 잰다. 화면의 뒷벽 거리 기준(후면 간격 + 개방 깊이)은 설명서마다의 기준을 그대로 따른다.
- RS84의 기호 4=564는 기준선이 본체 옆면이 아니라 폭 계산에 쓰지 않는다.

## 다음 단계의 진입 조건

1. **문 궤적:** 네 모델 설명서 도면에서 문짝 폭과 경첩 위치를 판독해 근거 파일(`research/evidence/`)에 쪽·도면 번호와 함께 남긴다. 판독한 문짝 폭으로 계산한 90° 개방 깊이가 설명서의 개방 깊이와 ±10mm 안에서 맞을 때만 호를 그린다. 맞지 않으면 그 모델은 지금의 참고선만 유지한다.
2. **벽 옆 설치:** 설명서에 벽과의 거리별 개방 각도 표나 그림이 있는 모델만 "벽까지 거리" 입력을 연다. 없는 모델은 확인 필요로 둔다.
3. **사진 합성:** 실측 경험자 검증(아래)에서 "2D 평면도만으로는 결정을 못 했다"는 구체적 장면이 2명 이상 반복될 때 범위를 정한다. 그때도 합성 화면에는 판정 문구를 넣지 않고, 합성에 쓴 기준 치수와 오차를 같이 표시한다.
4. **3D:** 제조사가 공개한 치수 도면으로 만든 모델의 바깥 치수를 설명서 값과 대조해 ±5mm 안일 때만 쓴다. 사진 합성보다 먼저 하지 않는다.

## 실제 사용자에게 확인할 것

[현장 검증 기록지](salimlab-consumer-tool-user-check-2026-10-29.md)의 설치 확인 과제에서 냉장고 참가자에게 추가로 본다.

- 번호 표식(①~⑦)과 아래 목록을 짝지어 읽는지, ②와 ③을 같은 문 개방 범위로 오해하지 않는지
- 빨간 겹침 칸을 보고 "문을 끝까지 못 연다"가 아니라 "설명서 개방 깊이만큼은 겹친다, 현장에서 다시 잰다"로 말하는지
- 예시 주방을 둘러본 뒤 우리 집 값으로 돌아왔을 때 값이 남아 있는 것을 알아차리는지, 예시값 결과를 자기 집 결과로 말하지 않는지
- 네 모델 비교표의 +값을 "들어간다"로 읽지 않는지
- 이 화면만으로 결정할 수 없었던 장면(벽 옆, 서랍 인출, 사람 통행 등)이 무엇인지 — 사진·3D 범위를 정하는 입력이다
