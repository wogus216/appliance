## 측정 사양

- **분석 단위:** 페이지(사이트맵 `<loc>` 1개 = 1페이지). 본문은 `<main>` 안 텍스트, `script`·`style`·`noscript`·`template`·`svg` 제외.
- **모집단:** 기준 빌드(`6165438`, `npx next build --webpack`)의 `out/sitemap.xml` 106 URL 전부. 내부 링크 검사만 빌드 HTML 164개 전부.
- **기계 표시 기준(사전 고정):** 본문 1,000자 미만(공백 제외) = 짧음. `<main>` 안 외부 링크 0개 = 원문 링크 없음(소개·정책·목록 페이지 12개 제외). 제품·카테고리·브랜드·블로그에서 판단 요소 5계열(설치/사용조건/관리/근거/확인필요, 정규식) 중 2개 이상 없음 = 판단 부족 후보. 40자 이상 `p·li·dd·blockquote` 블록이 다른 한 페이지와 3개 이상 같음 = 문단 겹침. 링크 카드 문단(글자의 80% 이상이 링크 안)과 8쪽 이상에 나오는 템플릿 문단 11개는 겹침에서 뺐다.
- **표본(직접 읽기):** 제품 8, 블로그 5, 카테고리 4, 브랜드 4, 오류 허브 4, 도구 4 = 29쪽. 기계 표시가 걸린 페이지를 우선 넣고 품목이 겹치지 않게 골랐다. 읽기는 서브에이전트 3개가 나눠 했고(외부 웹 금지), 결과는 조정자가 소스·원자료와 대조해 고침/남김으로 나눴다.
- **심각도:** 높음 = 안전 규칙(가스·누수·과열·전기 코드에 원문 근거 없는 사용자 조치) 위반 의심. 중간 = 사실 불일치·페이지 간 판단 상충·근거 없는 출처. 낮음 = 문장·표기·라벨·날짜 표기.
- **데이터 시점:** 2026-10-29 15시대 KST. 스크립트는 세션 작업 폴더에만 두었다(커밋하지 않음).

## A. 소개·편집 원칙·계산 방법에 반영한 것
