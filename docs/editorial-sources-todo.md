효율관리기자재라 모델번호별 공공 근거가 될 수 있다고 보고 들어갔다. 사이트는 살아 있으나
`제품검색 > 효율등급제도`(`certification/certi_intro_01.aspx`)에 **검색 폼도 iframe도 없다.**
확인한 범위에서는 모델별로 인용할 수 있는 고유 URL을 얻지 못했다. 다른 진입 경로가 있을 수 있다.

`samsung-bespoke-jetbot-ai`(VR50T95735W)는 **미확인**이다 — 확인 도중 브라우저 제어권이
사용자에게 넘어가 중단했다. 8/24에는 삼성 지원 페이지가 HTTP 500이었다.

## 남은 8건은 출처를 더 뒤져서 풀리지 않는다

현재 허용목록(`src/lib/source-trust.ts`) 아래에서 두 번째 발행처가 존재하지 않는 것이
1차 소스로 확인됐다. 선택지는 셋이고 **전부 편집 정책 결정이라 코드로 판단할 수 없다**:

1. 허용목록에 대형 가격·스펙 DB를 한 곳 더 인정한다(에누리 등). 단 다나와와 **독립성이 약하다** —
   둘 다 제조사 자료를 옮겨 싣는 곳이라 "서로 다른 발행처 2곳"의 원래 취지가 희석된다.
2. 대형 유통사의 상품정보고시(롯데하이마트 등)를 근거로 인정한다. 법정 표시사항이라 정확도는
   있으나 유통사는 발행처가 아니라 판매처다.
3. 그대로 둔다 — 제품을 현행 모델로 교체하거나 공개 보류로 내린다.
