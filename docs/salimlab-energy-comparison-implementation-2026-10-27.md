# 냉장고 전기사용량 비교 구현 기록

작성일: 2026-10-27. [소비자 도구 기획](salimlab-consumer-utility-site-plan-2026-10-27.md)의 첫 묶음 중 두 번째 도구다. 로컬 구현과 검증을 마쳤으며 운영 배포 전이다.

## 사용할 수 있는 기능

- 기존 `/compare#energy-compare`에서 RF85C90D1AP, T873MEE111, RS84B5061M9, S834MWW1D 중 두 모델을 선택한다.
- 공단 월간 신고량, 연 환산량, 두 모델의 차이를 표와 막대로 표시한다. 단위가 같아도 개별 시험 조건의 일치를 보장하지 않는다는 한계를 함께 표시한다.
- 선택 모델을 `energyA`·`energyB` 주소에 담아 공유한다. 기존 제품 사양 비교의 `items`와 함께 사용할 수 있다.
- 모델별 원문, 신고번호, 신고 용량, 완료일, 시험기관, 확인일을 제공한다. 제조사 판매 용량과 치수·설치 안내는 구별해 표시하고 제품 상세의 적합성 항목으로 연결한다.
- 결과와 근거를 복사한다. 클립보드를 사용할 수 없으면 직접 복사할 입력란을 제공한다.
- 홈과 지원하는 네 제품 상세에 진입 링크를 연결했다.

기본 쌍 RF85C90D1AP/T873MEE111의 신고량 차이는 월 0.57kWh, 연 환산 6.84kWh다. RS84B5061M9/S834MWW1D의 차이는 월 0.63kWh, 연 환산 7.56kWh다. 실제 전기요금이나 가정의 절약액으로 표시하지 않는다.

## 근거와 계산 범위

네 공단 원문을 2026-10-27 다시 확인했다. 수치·용량·날짜·원문 링크는 [근거 기록](../research/evidence/2026-10-27/fridge-energy-source-check.md)에 있다. RS84B5061M9의 현재 완료일자는 비어 있어 과거 자료로 채우지 않았다.

`src/lib/data/energy-measurements.ts`를 수치 원본으로 사용한다. 기존 제품 사양표도 이 레코드를 읽어 같은 신고량을 사용한다. 비교 로직은 월간 신고량을 소수점 두 자리 정수로 바꿔 차이를 계산한다. 연 환산은 월간 신고량의 12배다.

지원하지 않는 모델, 같은 모델, 다른 품목·단위·자료 묶음, 유효하지 않은 숫자는 비교 결과를 만들지 않는다. 주소에 지원하지 않는 모델을 넣었을 때 기본 모델로 대체하지 않는다. 사용자의 전기계약·누진 구간·실사용량을 입력받거나 실제 요금을 추정하는 기능은 이번 범위에 없다.

## 구현 위치

- `src/lib/energy-comparison.ts`: 계산, 모델 선택 해석, 주소·복사문 생성
- `src/lib/data/energy-measurements.ts`: 네 모델의 확인된 신고 수치
- `src/lib/fridge-energy.ts`: 제품 데이터에서 공개 화면용 정보 구성
- `src/components/compare/energy-comparison.tsx`: 선택·결과·출처·설치 안내
- `src/lib/__tests__/energy-comparison.test.ts`: 계산·근거 연결·예외·초기 렌더링 검증

## 검증

- 새 비교 관련 단위 테스트 20개 통과. 전체 27개 파일, 2,001개 테스트 통과.
- 변경한 전기량 관련 코드의 ESLint 통과.
- 정적 빌드와 TypeScript 검사 통과. 157개 페이지 생성.
- 데스크톱 1280px·모바일 390px 브라우저 검사 32개 통과: 계산, 출처, 복사와 실패 시 대안, 주소 복원, 미지원·중복 모델 차단, 기존 사양 비교와 주소 공존, 홈·제품 상세 진입, 가로 넘침·하이드레이션 오류 확인.
- 생성된 정적 산출물에서 모델 주소 복원·새로고침, 제품 상세·홈 진입, JavaScript 없이 기본 결과 표시, JavaScript 예외 없는 동작을 확인했다.

아직 실제 구매 예정자의 이해도와 의사결정 도움을 확인하지 않았다. 운영 배포일에 맞춘 사이트 수정일 갱신, 배포, 운영 화면 확인도 남아 있다. 이번 결과를 사용자 수요 검증으로 해석하지 않는다.
