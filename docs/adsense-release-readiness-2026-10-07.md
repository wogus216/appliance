# 살림랩 AdSense 후속 검수와 배포 점검 2026-10-07

삼성·LG·SK매직의 남은 모델 오류 안내와 기능 주장을 정정하고, 귀뚜라미 제품군별 코드 및 나비엔 공급·누수 조치를 구분했다. 기존 벤치마킹 계획의 세 번째 파일럿으로 쿠쿠 CDW-A0611T E4 상세 안내를 추가했다. 계정 로그인과 실제 AdSense 심사 상태 확인은 콘텐츠 검증과 별도로 진행한다.

## 변경과 근거

- [삼성·LG 정확한 모델 검수](../research/evidence/2026-10-07/samsung-lg-exact-model-code-scope-audit.md): 공통 코드표와 개별 모델 표시를 분리하고, LG 냉장고의 에러 표시 시 전원 유지 안내를 우선한다.
- [보일러 검수](../research/evidence/2026-10-07/boiler-code-scope-audit.md): 귀뚜라미 10·98의 서로 다른 뜻과 95 수동 보충 조건, 나비엔 찬물·온수 공급 및 누수 상담 대상을 구분한다.
- [쿠쿠 E4 상세 근거](../research/evidence/2026-10-07/cuckoo-e4-pilot-source-check.md): 적용 모델·전원과 급수 차단·E1과 dr의 차이·서비스 기록을 안내한다. 기존 계획의 네이버 노출 91회가 후보 선정 근거다.
- 10월 2일의 미배포 LG·삼성·SK매직 수정도 함께 반영한다. Haier F25·Coway 보강은 이미 `791e514`로 배포됐으므로 다시 새 작업으로 처리하지 않는다.

## 검증

전체 테스트 23개 파일의 1,904개 항목, ESLint, TypeScript와 정적 빌드가 통과했다. 빌드는 156개 정적 페이지를 생성하며 사이트맵은 101 URL이다. 비교 44개는 기존대로 noindex이며 사이트맵에 없다.

배포 전 라이브 HTML과 정적 산출물의 main 본문을 대조해 바뀐 경로만 `SITE_REVISIONS`에 기록했다. 기존 사이트맵은 98 URL이고, 신규 E4와 기존 LG 제품 두 페이지의 색인 자격 변경으로 101 URL이 된다. 이는 Google의 실제 색인 수가 아니다.

## 배포와 계정 확인

`10704ea`를 main에 푸시했고 [GitHub Actions 배포](https://github.com/wogus216/appliance/actions/runs/37554836015)가 성공했다. 라이브 사이트맵 101 URL 모두 HTTP 200이며, 101개 main 본문이 로컬 빌드와 모두 일치한다. 새 쿠쿠 E4의 canonical·색인 허용·허브 링크와 건조기 TC5·LG 냉장고 전원 유지 안내를 확인했다. 제거한 Coway·Dyson·Winix 오류 허브는 404다.
