# 남은 소비자 도구의 로컬 구현 — 2026-10-29

## 사용 가능한 경로

- `/tools/repair-replace`: 받은 수리 견적과 새 제품의 확인된 비용을 비교한다. 포함 항목 미확인은 부분 합계로 표시하고, 보증·진단·수리 후 보증 질문을 남긴다. 사용자가 입력한 금액은 주소·서버에 저장하지 않는다.
- `/tools/home-energy`: 기기별 누적 kWh와 측정 일수를 30일로 환산한다. 냉장고 네 모델은 한국에너지공단 월간 신고값을 나란히 표시하되 시험값과 실측값을 같은 조건의 차이로 해석하지 않는다. 요금은 계산하지 않는다.
- `/tools/dishwasher-fit`: 쿠쿠 CDW-A0611TW와 SK매직 DWA-81R0D의 본체 치수를 설치 자리와 비교한다. 쿠쿠는 문을 연 깊이 812mm까지 확인한다. SK매직의 문 개방 깊이는 미확인으로 남긴다. 급수·배수·전원·수평은 상담 자료 체크 항목이다. [기존 공식 설명서 대조 글](../src/lib/data/blog/posts/dishwasher-12-vs-6-countertop.ts)을 재사용한다.
- `/tools/household-care`: 기존 34개 공개 모델의 관리 항목을 여러 개 추가하고 날짜순으로 본다. 설명서 주기 9개 항목만 마지막 관리일로 계산한다. 나머지는 사용자가 날짜를 정한다. 저장 위치는 현재 브라우저의 localStorage이며 계정·알림은 없다.
- `/tools/fridge-fit`: 기존 2D 참고도에 두 가지 가상 주방 치수 선택을 추가했다. 예시 치수는 입력값·결과·복사 기록에서 계속 예시로 표시하며, 실제 집 치수로 전환할 때 모든 예시값을 비운다.

홈에는 고르기·설치하기·쓰기/관리하기·고장 해결하기·수리/교체하기의 다섯 출발점을 두고, 관련 도구와 제품 상세에서 이어지게 했다.

## 확인과 남은 검증

- 새 계산 도구와 설치·관리 목록의 경계 조건을 단위 테스트로 확인했다.
- Next.js 16.2.12에서 `next build --webpack` 정적 빌드를 확인했다. 이 환경의 기본 Turbopack 빌드는 CSS 처리 중 로컬 포트 바인딩 제한으로 실패한다.
- 사용자가 실제 견적·전력 측정·설치 치수·관리 항목을 넣어 보고, 결과의 다음 행동과 미확인을 정확히 이해하는지는 아직 검증하지 못했다.
- 냉장고 예시 주방은 수치 기반 참고도이며 실제 가구 배치·사진·3D 배치는 아직 없다. 실측 경험자에게 2D 참고도의 효용을 먼저 확인한다. 제품별 추가 설치 도구는 정확 모델의 설치 문서에서 치수와 조건을 대조한 뒤 연다.
