# 정수기 기술 지도와 관리 카드 구현

작성일: 2026-10-27. [소비자 도구 기획](salimlab-consumer-utility-site-plan-2026-10-27.md)의 두 번째 묶음 중 첫 항목을 로컬 구현했다. 운영 배포와 사용자 이해도 검증은 남아 있다.

## 사용할 수 있는 기능

- 기존 CHPI-7400N 제품 상세의 ‘상세 스펙과 근거’에 기술 지도를 넣었다. 해당 모델의 목차는 이 절을 ‘기술·관리’로 안내한다.
- 나노트랩·플러스이노센스(D) 필터와 정수·냉수·얼음·온수, 여섯 항목을 선택하면 원리·생활에서의 해석·관리할 곳·자료 한계가 바뀐다.
- 지도는 필터 순서와 기능별 방식을 연결한 원리 도식이다. 정수 직수식, 냉수 1L 칠링존, 얼음 0.74kg 저장고, 순간온수의 차이를 보여 준다. 내부 배관의 실제 위치나 분기를 재현하지 않는다.
- 필터 세트, 출수구, 물받이, 저장고의 관리 내역 확인 카드를 제공한다. 확인 상태를 포함한 설명·근거·주소를 복사하거나 텍스트로 저장하고, 복사가 막히면 직접 선택할 기록을 보여 준다.
- 온수 정격 2,950W와 공단 월간 신고 12.17kWh를 별도 출처로 설명한다. 실제 사용량·요금으로 환산하지 않는다.
- 홈에 지도 진입 링크를 넣고 정확 모델의 기존 제품 페이지를 사용했다. 새 페이지와 사이트맵 항목은 만들지 않았다.

진입 주소: `/products/coway-handpick-water-purifier-compact#technology-map`.

기능별 주소 예: `?tech=ice#technology-map`. 선택한 기능은 주소로 복원하며 체크 상태는 브라우저 메모리에만 있어 새로고침하면 비워진다. 지원하지 않는 항목은 기본 설명으로 대체하지 않고 선택 안내를 보여 준다. CPI-7400N과 다른 정수기에는 이 모델의 지도를 표시하지 않는다.

## 근거와 제약

[공식 자료 대조 기록](../research/evidence/2026-10-27/purifier-technology-source-check.md)에 설명서 쪽 번호·재수신 해시·신고 자료와 표현 범위를 남겼다.

- 필터 4개월은 하루 10L와 상수도 수질을 고려한 예상 주기다. 저장고 청소에는 확인하지 못한 고정 주기를 넣지 않았다.
- 체크는 관리 내역 확인이며 세척·교체 완료나 수질 판정이 아니다. 정수량이나 도식만으로 남은 필터 수명을 계산하지 않는다.
- 청소와 필터 자가 교체의 전원 조건이 달라 전체 절차를 원문에서 확인하도록 안내한다. 내부 분해·배관 수리 절차를 만들지 않는다.
- 기능 선택은 native History API와 Next의 검색 매개변수 동기화를 사용한다. 원문·기본 설명·관리 항목은 정적 HTML에도 표시한다. 각 노드는 키보드로 누를 수 있는 일반 버튼이며 선택 상태를 `aria-pressed`로 알린다.
- 움직임 없이 선택 강조와 설명 교체만으로 흐름을 보여 준다. 기존 제품 페이지의 색·서체·폼 스타일을 따른다.

## 구현 위치

- `src/lib/purifier-technology.ts`: 타입, 기능 선택 해석, 주소·카드 기록
- `src/lib/data/purifier-technology.ts`: 정확 모델의 구조화한 기술·관리·근거
- `src/components/detail/purifier-technology.tsx`: 도식, 기능 설명, 확인표, 복사·파일 저장
- 기존 성능 절·목차·홈에 연결

## 검증

- 신규 관련 단위 테스트 16개 통과. 정확 모델 범위, 저장·직수 구별, 주기 조건, 단위·출처 분리, 주소 복원, 관리 기록, 정적 HTML과 제품별 렌더링을 확인했다.
- 전체 29개 파일·2,038개 테스트 통과.
- 변경 코드 ESLint, TypeScript·정적 빌드 통과. 기존과 같은 158개 페이지 생성.
- 데스크톱 1280px·모바일 390px 브라우저 검사 52개 통과. 여섯 기능 선택과 단일 선택 상태, 키보드 조작, 주소·새로고침 복원, 미지원 항목, 복사·저장 파일·복사 실패 대안, 홈 진입과 다른 제품 미표시, 가로 넘침·JavaScript 오류를 확인했다.
- 생성된 정적 산출물에서 기능 주소 진입·선택 변경·새로고침, canonical, 홈 링크를 확인했다. JavaScript 없이도 기본 설명·관리 항목·원문 링크가 표시되고 브라우저 예외가 없었다.

다음 작업은 날짜를 넣어 다음 관리 시점을 확인하고 인쇄·달력 파일로 가져갈 수 있는 관리 일정표다. 계정·알림은 이번 구현에 포함하지 않는다. 운영 배포 시 실제 배포일의 본문 변경 경로 수정일을 반영해야 한다.
