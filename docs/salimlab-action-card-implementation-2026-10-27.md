# 오류코드 이후 행동 카드 — 구현과 적용 모델 확장

작성일: 2026-10-27

## 구현 결과

기존 상세 안내에 **정확 모델 확인 → 상태 기록 → 다음 행동 → 상담 기록 복사·텍스트 저장**을 연결했다.

| 상세 안내 | 적용 모델 | 행동 분기 |
| --- | --- | --- |
| `/error-codes/Cuckoo/dishwasher/e4#action-card` | CDW-A0611TW·CDW-A0611TS | 전원·급수 차단 및 서비스 요청. 표시가 사라져도 세척 재개를 권하지 않음 |
| `/error-codes/Haier/air-conditioner/f25#action-card` | CTH06QBW·CTH10QBW | 정확 모델·안전 상태·외기 온도·조치 후 상태를 확인. 온도 미확인·0℃ 이상·재발에는 재시작을 권하지 않음 |
| `/error-codes/SKMagic#action-skmagic-dr` | DWA19R0P·DWA19C0P·DWA19C1P | dr 문 닫힘 확인. 반복되면 서비스 요청 |
| `/error-codes/SKMagic#action-skmagic-f9` | DWA-81R0D·R1D·U0D·U1D·R5B·R6B·U5B·U6B | 공용 설명서의 F1~F9 기능 이상 조치. 표시가 사라져도 서비스 요청 |
| `/error-codes/Roborock#action-roborock-s7-error2` | S7 | 범퍼 걸림 확인. S7 MaxV·S8 등 다른 모델에 적용하지 않음 |

사용자의 추가 모델 요청으로 기존 4개에서 **16개 모델·5개 모델/코드 안내**로 확장했다. 행동을 두 제품 ID에 고정했던 부분을 근거와 조치 데이터로 옮겼다. 같은 화면의 여러 폼은 서로 다른 입력 ID와 라디오 그룹을 사용하며 저장 기록에는 해당 폼의 고유 앵커를 넣는다.

모델명이 일치하지 않으면 다른 모델의 설명서·점검 조치를 기록에 넣지 않는다. 사용자는 빈 모델명으로도 진단을 포함하지 않는 문의 기록을 만들 수 있다. 안전 문제를 신고하면 모델 확인보다 중단 안내가 우선한다. 입력을 바꾸면 이전에 만든 결과는 숨겨 다시 생성하게 한다. 작성 내용은 서버로 전송하거나 저장하지 않는다.

복사·저장 기록에는 사용자 입력, 권장되는 다음 행동, 근거 설명서와 대조일, 공식 서비스 주소, 안내 버전 `2026-10-27.1`, 최신 안내 URL이 들어간다. 실제 조치한 것으로 표시하는 항목은 사용자가 직접 적은 내용이다. 클립보드를 사용할 수 없으면 수동 복사와 파일 저장을 안내한다.

브랜드 허브의 기존 상세 안내 링크에도 `AS 상담 기록 만들기`를 표시했다. 제품 상세와 오류 허브는 기존 상세 페이지 레지스트리를 계속 쓴다.

## 근거

- 쿠쿠: [기존 공식 원문 대조](../research/evidence/2026-10-07/cuckoo-e4-pilot-source-check.md). 2026-10-27 공식 URL에서 내려받은 PDF SHA-256이 기존 원문과 같은 `a2590ff4393d07341c286dd792a20ad02278565d716a81cd214683c7fd66e2c1`임을 확인했다. 안내에는 기존 대조일 2026-10-07을 유지했다.
- 하이얼: [국내 두 모델의 설명서 대조](../research/evidence/2026-10-02/haier-f25-model-specific-source-check.md). 기존 대조일 2026-10-02와 정확한 모델별 PDF를 표시한다. 이번 공식 홈 조회는 도구에서 시간 초과가 발생했다. 새 전화번호·상담시간을 추가하지 않고 공식 서비스 주소로 연결한다.
- 안전 상태 확인과 상담용 기록 양식은 살림랩의 편집 기능이다. 부품 고장·수리 완료·수리비를 자동 진단하지 않는다.
- SK매직 dr: [DWA19 공용 설명서](https://m.manual.skmagic.com/2019/model/DWA/DWA19R0P00BL/Manual.htm)의 TOUCH ON 절과 제품규격을 2026-10-27 다시 대조했다. 정확한 세 모델명과 문의 위쪽 끝을 눌러 닫는 조치를 확인했다.
- SK매직 F9: [터치온 공용 설명서](https://m.manual.skmagic.com/2019/model/DWA/DWA81R0D00SL/Manual.htm)의 자가 진단하기와 제품규격을 2026-10-27 다시 대조했다. [코드 그림](https://m.manual.skmagic.com/2019/model/DWA/DWA81R0D00SL/images/img_08_01_03.png)을 직접 열어 F1~F9임을 확인했다. 적용 모델 8개는 제품규격에 명시된 정확한 번호이며 접두사로 추정하지 않았다.
- 로보락 S7: [공식 영문 설명서](https://support.roborock.com/hc/en-us/article_attachments/900008254623) 인쇄 38~39쪽의 Error 2 범퍼 안내를 2026-10-27 다시 대조했다. 영문 설명서임을 카드의 근거에 표시했다.

## 검증

- 전체 테스트: 26개 파일, 1,964개 통과. 새 행동 분기 테스트 16개 포함.
- 마지막 문구·상세 링크 변경 후 관련 테스트: 3개 파일, 142개 통과.
- TypeScript 검사와 최종 정적 export 빌드 통과.
- 전체 ESLint: 오류 0. 기존 `.audit/naver-index/salimlab.kr/aside-batch.tpl.js`의 미사용 변수 경고 1개.
- 데스크톱 1280px·모바일 390px에서 브라우저 검사 35개 통과: 모델 누락·불일치, 안전 상태, 온도와 재발 분기, 실제 복사·다운로드, 복사 실패, 결과 초점, 입력 변경 후 이전 결과 제거, 가로 넘침, 브라우저 예외 확인.
- 최종 정적 export를 별도 로컬 서버에서 열어 두 브랜드 허브 링크 → 상세 도구 → 모델 확인 → 상담 기록 생성 흐름을 재확인했다.

모델 확장 후 전체 테스트는 **26개 파일·1,981개** 통과했고, 변경 파일 ESLint·TypeScript·최종 빌드도 통과했다. 추가 브라우저 검사 27개로 두 화면 폭의 고유 앵커 직접 열기, 폼 간 입력 독립성, 중복 DOM ID, F9와 dr의 모델 분리, S7 MaxV 차단, 실제 복사를 확인했다. 앵커 방문 때 브라우저가 닫힌 details를 먼저 여는 동작은 해당 요소의 초기화 속성 비교에서만 허용하며 다른 영역의 초기화 오류는 계속 검사한다.
