# 사양 대조 감사 (2차)

모델번호를 확인한 제품이라도 **사양이 맞는가**를 따로 물은 결과다.

## 측정 사양

- **분석 단위**: 제품 1건의 사양 필드(소비전력 W · 크기 3축 mm · 에너지효율등급)
- **모집단**: 공개 중인 35개 중 다나와 **본품** 상품 페이지를 확보한 **24개**
  - 본품 확보 실패 11개는 액세서리 판매글만 잡혀 대조 자체가 불가능했다.
  - 1차 감사의 '확인 32건'은 액세서리 언급도 근거로 인정한 수치다.
    본품 페이지 기준으로 다시 세면 **74개 중 24개**다. 정정이 아니라 **다른 집계**다.
- **비교 대상**: 양쪽 모두 값이 있는 항목만. 한쪽에만 있으면 분모에서 제외
- **허용 오차**: 크기는 축당 5mm 이내면 일치로 본다
- **데이터 시점**: 2026-08-23 · **출처**: 다나와 상품 페이지 스펙 요약

### 한계

- 다나와 스펙 요약은 제조사 공식 사양의 2차 자료다. 최종 근거로는 제조사 페이지를 봐야 한다.
- 불일치 중 일부는 **정의 차이**일 수 있다 — 로봇청소기 크기(본체 vs 도크 포함),
  세탁기 크기(단품 vs 건조기 적층 세트). 아래 표에 표시했다.

## 가장 무거운 것

**`samsung-wind-free-ar07a9170` 에너지효율등급 — 카탈로그 1등급, 다나와 4등급.**
이 값 하나가 10년 총비용 계산기와 "에너지등급이 전기요금에 미치는 영향" 표 전체를
움직인다. 1등급 대비 배율이 4등급은 1.9배다. 구매 판단을 직접 왜곡하는 오류다.

**복붙 흔적** — `haier-cth10qbw-wall`과 `tcl-tac-12csd-wall`의 크기가
둘 다 `870 x 292 x 210mm`로 **완전히 같다.** 서로 다른 제조사의 다른 모델이다.
실제 값은 각각 875x307x217, 788x275x192로 다르다.

## 함의

모델번호가 실재하는 제품에서도 사양이 틀렸다. 즉 **모델번호 감사를 통과한 것이
사양의 신뢰를 보장하지 않는다.** 소음(dB)과 월 전기요금은 다나와가 표기하지 않아
대조조차 못 했는데, 소비전력이 30~40% 틀린 것을 보면 같은 방식으로 만들어졌다고
봐야 한다. 월 전기요금은 TCO 계산기의 입력값이다.
