# 살림랩: 소비자의 가전 결정을 돕는 콘텐츠 사이트

작성일: 2026-10-27

## 제품 약속

살림랩에 들어온 사람은 제품을 **고르기, 집에 들이기, 계속 쓰기, 문제가 생겼을 때 해결하기** 중 한 가지 일을 끝낼 수 있어야 한다. 제품 목록은 이 일을 돕는 자료다. 각 화면은 스펙뿐 아니라 **내 조건 → 확인된 근거 → 선택지 → 지금 할 일**을 제공한다.

처음에는 한국에서 실제로 구할 수 있는 정확한 모델과 한국의 전기요금·서비스 환경을 다룬다. [세계 생활 문제 조사](global-appliance-household-problems-research-2026-10-26.md)는 문제를 찾는 데 참고하되, 해외 수치와 제도를 한국 사용자의 결과로 옮기지 않는다.

## 근거와 현재 자산

- [Google AdSense의 사이트 준비 안내](https://support.google.com/adsense/answer/7299563?hl=en)는 방문자에게 관련 있고 독자적인 콘텐츠, 쉬운 탐색, 좋은 사용 경험을 요구한다. [Google Search Central](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)은 자료를 모아 다시 쓰는 경우에도 추가 분석과 독자적 가치를 보여 주라고 권한다. 아래 기능이 승인이나 색인을 보장한다는 뜻은 아니다.
- [EU 2025 소비자 조사](https://www.europarl.europa.eu/meetdocs/2024_2029/plmrep/COMMITTEES/IMCO/DV/2025/05-19/consumer_conditions_scoreboard_2025_EN.pdf)에서 보증이 끝난 내구재를 수리하지 않은 이유로 비용 61%, 수고 32%, 오래 걸림 28%가 보고됐다. 가전만의 조사 결과가 아니며, 한국 사용자의 수요는 따로 검증해야 한다.
- [미국 에너지부의 가전 안내](https://www.energy.gov/sites/default/files/2021-08/ES-KitchenAppliances_080221.pdf)는 구입가와 운영에 드는 에너지·물 비용을 함께 보도록 안내한다. 한국 제품에는 [한국에너지공단 신고 자료](https://eep.energy.or.kr/report/report.aspx)를 정확한 모델과 시험 단위로 대조한다.
- 현재 홈 `src/app/page.tsx`는 오류코드 검색, 최근 글, 제품 스펙 그리드로 이어진다. 제품 상세 `src/app/products/[slug]/page.tsx`에는 적합성·비용·위험·성능·근거가 있지만 방문자의 생활 과제별로 연결되지는 않는다. 기존의 에러코드 검색, 비교 글, 모델별 치수·전기사용량·공식 출처를 다시 사용할 수 있다.

각 결과는 링크로 공유하거나 인쇄할 수 있는 **한 장의 판단 카드**로 끝난다. 예를 들어 냉장고 카드에는 `폭은 맞음 / 문 개방 폭은 확인 필요 / 공단 신고 전력량 차이는 월 0.57kWh / 배송 동선 실측 필요`처럼 확인된 사실과 미확인을 나눠 쓴다. 출처·측정 조건·확인일을 카드에서도 볼 수 있어야 한다.

## 사이트 구조

홈의 첫 질문은 **“지금 가전 때문에 무엇을 하려고 하나요?”**다. `고르기 / 설치하기 / 쓰기·관리하기 / 고장 해결하기 / 수리·교체하기`에서 출발한다. 기존 제품·브랜드·오류코드 탐색은 그대로 접근 가능하다. 제품 상세는 해당 모델을 중심으로 도구 결과와 설명서를 연결하는 허브가 된다.

```text
생활 과제 선택
  ├─ 조건 입력 → 판단 카드 → 관련 모델·근거 문서
  └─ 모델 선택 → 제품 허브 → 설치·전기·관리·문제 해결
```

검색 유입용 페이지도 도구만 놓지 않는다. 대표 사례, 계산 과정, 정확한 모델과 자료 범위, 사용자가 다음에 확인할 일을 본문에 담는다. 동일 문구를 모델명만 바꿔 대량 생성하지 않는다.

## 실제 출시 순서

### 첫 묶음: 당장 쓰는 세 가지 일

1. **오류코드 이후 행동 카드:** 현재 에러코드 안내에서 정확 모델 확인, 안전한 점검, 중단 기준, AS 문의 문장으로 연결한다. 2026-10-27에는 쿠쿠 E4·하이얼 F25부터 로컬 구현한 뒤, SK매직 dr·F9와 로보락 S7 Error 2를 더해 16개 모델·5개 안내로 넓혔다. 모델명과 상태를 입력하고 기록을 복사하거나 텍스트로 저장한다. 운영 배포와 실제 사용자 효용 검증은 남아 있다. 적용 범위와 검증 결과는 [구현 기록](salimlab-action-card-implementation-2026-10-27.md)에 둔다.
2. **냉장고 4개 모델의 전기사용량 비교:** 2026-10-27 기존 비교 페이지에 로컬 구현했다. 정확 모델 두 개의 공단 월간 신고량과 연 환산 차이, 출처·확인일, 제조사 치수·설치 안내를 연결한다. 홈과 해당 제품 상세에서 진입하고 선택한 모델을 주소로 공유한다. 같은 공개 신고 항목을 비교하되 개별 시험 조건이 동일하다고 단정하거나 실제 전기요금으로 환산하지 않는다. 운영 배포와 구매 예정자의 효용 검증은 남아 있다. 적용 범위와 검증 결과는 [구현 기록](salimlab-energy-comparison-implementation-2026-10-27.md)에 둔다.
3. **냉장고 설치 전 확인표와 공간 배치:** 2026-10-27 네 모델의 설치 전 확인표와 실측값에 반응하는 2D 참고도를 `/tools/fridge-fit`에 로컬 구현했다. 자리 폭·본체 높이·문 개방 폭·뒷벽부터 거리를 따로 비교하고 반입 경로는 상담 항목으로 남긴다. 미측정·부족·설명서의 다른 기준점을 구별하며 전체 설치 가능 판정은 하지 않는다. 홈·제품 상세·전기량 도구에서 이어지고 상담 기록을 복사·저장한다. 운영 배포와 실측 경험자의 효용 검증은 남아 있다. [구현 기록](salimlab-fridge-fit-implementation-2026-10-27.md) 참고.

세 도구는 서로 다른 생활 시점에서 바로 사용 가능해야 한다. 홈에는 `전기량 비교`, `우리 집에 들어올까`, `고장 났어요`라는 과제별 진입점을 둔다.

오류코드 기능의 구현과 구매·설치 콘텐츠의 근거 조사·시안 검증을 함께 진행할 수 있다. 여러 기능을 제공하는 장기 방향을 유지하며, 첫 도구의 효과를 다른 기능의 수요로 간주하지 않는다. 로컬 Google 검색 자료(2026-10-27 저장, 측정 9월 25일~10월 24일)는 클릭 0·노출 11로 첫 대상을 결정하기에 부족하다. 쿠쿠 E4 선택은 과거 네이버 수요 기록과 모델별 공식 원문 확보에 근거한 초기 가설이다.

### 두 번째 묶음: 산 뒤에도 돌아올 이유

4. **정수기 한 모델의 기술 지도와 관리 카드:** 2026-10-27 CHPI-7400N 제품 상세에 여섯 항목을 선택하는 기술 지도와 관리 확인 카드를 로컬 구현했다. 필터 순서·직수와 저장부·순간온수를 원리 도식으로 보여 주며 실제 내부 배치를 재현하지 않는다. 필터 교환 주기의 조건, 별도 청소 항목, W와 kWh/월의 차이, 원문을 연결하고 카드 복사·저장을 제공한다. 운영 배포와 사용자 이해도 검증은 남아 있다. [구현 기록](salimlab-purifier-technology-implementation-2026-10-27.md) 참고.
   - 2026-10-28 사용자 요청으로 쿠쿠 CDW-A0611TW·삼성 DV17A9720BV·로보락 S8 Pro Ultra를 더해 총 네 모델로 넓혔다. 품목별 기능·관리 연결도와 정확 모델의 관리 기준·공식 근거를 제공한다. [확장 구현 기록](salimlab-appliance-technology-expansion-2026-10-28.md) 참고.
   - 같은 날 ‘제품마다’ 적용 요청에 따라 나머지 30개를 더해 현재 공개 중인 12개 품목·34개 제품 모두에 적용했다. 모델별 기능·사용 조건·관리 항목과 공식 근거를 연결하고 홈에서 전체 모델을 찾도록 했다. 미확인 관리 주기와 기능 제약을 표시하며 숨김·미검증 제품의 공개 범위는 넓히지 않았다. 로컬 구현·검증 완료, 운영 배포 전이다. [전체 제품 적용 기록](salimlab-all-products-technology-2026-10-28.md) 참고.
5. **관리 일정표:** 2026-10-28 공개 제품 34개에서 모델별 관리 항목을 고르고 날짜를 입력하는 도구를 로컬 구현했다. 설명서에서 날짜 주기를 확인한 9개 항목만 다음 확인일을 계산하며, 나머지는 사용자가 확인일을 직접 정한다. 한 번의 달력 일정·인쇄·텍스트 복사를 제공한다. 운영 배포와 실제 사용자 검증은 남아 있다. [구현 기록](salimlab-care-plan-implementation-2026-10-28.md) 참고.
6. **수리·교체 비교표:** 공식 진단이나 사용자 견적이 없는 상태에서는 가격·수명을 만들어 내지 않는다.
   - 2026-10-29 `/tools/repair-replace`에 사용자가 받은 수리 견적과 새 제품 가격·확인된 추가비를 입력하는 판단 카드를 로컬 구현했다. 포함 비용이 미확인이면 부분 합계로 표시하고 보증·진단·수리 후 보증 질문을 남긴다. 가격·남은 수명·재고장 확률을 추정하지 않는다. 운영 배포와 실제 사용자 검증은 남아 있다.

### 이후 검증할 확장

사용자가 입력한 실측 kWh, 집 사진에 가전 배치하기, 여러 제품을 묶은 집 전체 관리표는 입력 부담과 자료 정확도를 먼저 확인한다. 3D 공간은 2D 도면으로도 설치 결정을 못 하는 경우가 발견될 때 만든다.

2026-10-29 로컬 확장: `/tools/home-energy`에 사용자 실측 kWh의 30일 환산과 정확한 냉장고 네 모델의 공식 월간값 병치를 구현했다. `/tools/dishwasher-fit`에 식기세척기 두 모델의 설치 치수·급배수 상담 확인표를 구현했다. `/tools/household-care`에는 34개 모델의 관리 항목을 브라우저 안에 모아 보는 목록을 구현했다. 홈의 첫 화면도 생활 과제 다섯 가지를 선택하는 구조로 바꿨다. 모두 실제 사용자 검증과 운영 배포 전이다. 집 사진·3D 배치와 알림·계정 동기화는 아직 구현하지 않았다.

2026-10-29 점검: 네 도구를 실제 브라우저로 조작해 입력 해석·예시값 덮어쓰기·인쇄·복사 문구 위치 오류를 고치고, 결과와 기록의 숫자마다 값 종류(공식·실측·계산·예시·확인 필요)를 붙였다. 냉장고 평면도에 맞은편 가구와의 겹침·남는 거리와 네 모델 비교를 더했고, 식기세척기 설치 조건을 원문 재대조로 `공식 자료/확인 필요`로 나눴다. 문 궤적·사진·3D에 필요한 자료와 진입 조건은 [가상 공간 다음 단계](salimlab-virtual-space-next-2026-10-29.md)에, 점검 내용은 [남은 도구 구현 기록](salimlab-remaining-tools-implementation-2026-10-29.md)에 둔다. 실제 사용자 검증은 미실시다.

## 공통 편집·데이터 규칙

- **정확한 모델 식별:** 기본 모델명, 파생 모델, 실내외기 조합을 혼동하지 않는다.
- **수치의 종류:** 공식 시험·제조사 주장·사용자 실측·계산·추정을 별도 표시한다. `W`, `kWh/회`, `kWh/월`, `kWh/년`을 단위 없이 합치지 않는다.
- **근거 연결:** 각 주요 주장에 문서 URL, 해당 쪽 또는 절, 확인일, 적용 모델, 시험 조건을 저장한다. 자료가 없으면 `확인 필요`로 출력한다.
- **실생활 결론:** 도구가 답한 질문과 아직 답하지 못한 질문을 함께 적는다. 할인·제휴 링크가 있더라도 판단 근거와 분리한다.
- **안전:** 누수·전기·가스·냉매와 관련된 증상은 자가 수리 단계로 확장하지 않는다. 설명서에서 허용한 점검과 서비스 연락 기준만 표시한다.
- **적용·정정:** 모델이 정확히 일치하지 않으면 모델별 행동 안내를 생성하지 않는다. 안전 상태가 미확인이면 재시작 안내를 보류한다. 출처 충돌·정정이 발견되면 담당 운영자가 해당 모델을 행동 카드 대상에서 제거하고 기존 본문도 함께 수정한다. 변경된 안내에는 새 버전을 부여하며, 저장 기록의 최신본 URL에서 정정 내용을 확인할 수 있게 한다. 서비스 연락·보증 정보는 해당 페이지를 다시 공개하거나 수정할 때 공식 안내로 대조하고, 변경 신고가 들어오면 즉시 재검수한다. 고정 치수와 모델별 안전 절차도 설명서 개정 또는 충돌 발견 시 다시 대조한다.

## 성공 여부를 확인하는 방법

실제 구매·설치·고장 경험자에게 첫 묶음 도구를 사용하게 한다. 5명씩 인터뷰해 **① 자기 상황에 맞는 경로를 찾았는지, ② 한 장의 카드를 보고 다음 행동을 말할 수 있는지, ③ 근거와 추정을 구별했는지**를 기록한다. 사용 중 막힌 입력과 잘못 이해한 결론을 먼저 수정한다. 이후에는 도구 시작 대비 카드 완성, 카드 공유·인쇄, 관련 설명서 또는 AS 이동, 재방문을 본다. 페이지 수·체류 시간·광고 승인 여부만으로 소비자 가치를 판단하지 않는다.
