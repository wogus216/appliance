# 가상 공간에서 가전 활용성 확인 — 2026-10-26

## 사용자가 얻어야 할 답

“이 제품이 예뻐 보이나?”와 함께 “**우리 집에 들일 수 있고, 놓은 뒤에도 문을 열고 지나가고 관리할 수 있나?**”를 확인한다. 제품 한 대의 본체 크기보다 **반입 동선, 문이 열리는 범위, 방열·작동 여유, 콘센트·급배수 위치, 사람이 서는 자리**가 결론을 바꿀 수 있다. 가상 장면은 실제 치수를 입력할 때만 설치 적합성 판단에 쓴다.

## 현재 살림랩 자료로 할 수 있는 것

- 냉장고: 삼성 RF85·RS84, LG T873·S834에는 정확한 본체 치수와 문을 열었을 때 필요한 폭·깊이, 일부 반입 조건이 기록돼 있다. 모델별 설치 문서의 요구 범위가 다르고 LG 자료는 설치 절과 고장 진단 절의 측면 여유가 서로 달라 **값이 충돌할 때 자동 ‘설치 가능’ 판정은 하지 않는다**.
- 식기세척기: 쿠쿠 6인용은 본체 가로 550·깊이 515·높이 438mm, 문을 열면 뒷면부터 812mm가 필요하다는 자료가 있다. 수도·배수·전원 위치도 확인해야 한다.
- 로봇청소기: 도크 본체뿐 아니라 앞·옆·위 여유 공간과 수평 바닥, 급배수형의 싱크대 조건이 중요하다. [로보락 공식 지원 자료](https://support.roborock.com/hc/en-us/articles/360035732031-What-should-I-do-when-the-robot-cleaner-cannot-find-its-dock)도 도크 좌우 0.5m·앞 1.5m의 예를 들지만 **정확한 모델의 설명서**를 우선한다.
- 현재 제품 이미지와 설명 문장은 있으나 크기가 검증된 3D 모델은 없다. 따라서 이미지 합성은 분위기 미리 보기로, 치수 계산은 별도 2D 도면으로 다룬다.

## 첫 시범 화면: 냉장고가 놓인 주방

1. **가상 주방 선택:** 작은 주방·일자형 주방 등의 예시 공간을 연다. 기본 치수는 예시라는 표시를 붙인다.
2. **실제 집 값 입력:** 냉장고 자리의 내측 폭·깊이·높이, 벽 위치, 앞 통로 폭, 현관·복도·주방 입구의 최소 폭을 잰다. 모르면 칸을 비워 둔다.
3. **정확한 모델 배치:** 평면도에 본체 실측 치수를 놓고 문을 여는 순간의 점유 범위와 방열 여유를 다른 색으로 보여 준다. 값마다 제조사 설명서의 출처와 적용 모델을 연결한다.
4. **생활 장면 시험:** 문을 열었을 때 맞은편 서랍·식탁·사람의 이동이 겹치는지, 냉동실을 사용할 자리가 남는지 확인한다. 반입 경로가 좁으면 구매 전 기사에게 확인할 치수·사진 목록을 만든다.
5. **선택 카드:** 같은 자리의 후보 두 대가 모두 들어간다면 공간 차이와 공식 `kWh/월` 차이를 함께 보여 준다. 전기량은 [전기사용량 판단 도구](appliance-energy-decision-feature-brief-2026-10-26.md)의 시험 조건 비교값으로 표시한다.

출력 예시: **“본체는 자리 폭에 들어가지만, 문을 열면 앞 통로가 좁아집니다. 좌측 벽과의 간격은 확인되지 않아 설치 가능 여부는 보류합니다. 설치 상담 전에 이 두 곳을 재세요.”** 확실하지 않은 값을 0mm로 취급하지 않는다.

## 단계별 제작

| 단계 | 사용자 경험 | 필요한 근거 | 출판 조건 |
| --- | --- | --- | --- |
| 1. 예시 주방 + 2D 평면도 | 모델을 바꿀 때 본체·문 열림·통로가 움직임 | 정확한 모델 치수와 문 개방 범위 | 모든 표시가 같은 모델의 출처에 연결됨 |
| 2. 우리 집 치수 입력 | 맞음·부족·미확인 항목과 기사 질문을 얻음 | 제조사 설치 여유·반입 조건 | 여유값이 모호하면 설치 확정 문구를 내지 않음 |
| 3. 전기 사용량 연결 | 공간이 맞는 후보 사이에서 신고 kWh 차이 해석 | 동일 단위의 공단 신고값 | 시험값과 실측값을 구분 |
| 4. 사진/3D 보기 | 실제 공간 느낌을 미리 봄 | 촬영 허락·제품 이미지 사용 조건·크기 검증 | 합성 이미지로 설치 가능을 판정하지 않음 |

## 이 기능이 기존 목록과 달라지는 지점

첫 화면의 질문이 “냉장고 4대 비교”에서 **“이 주방에 들일 냉장고를 고른다”**로 바뀐다. 제품 스펙과 공식 설명서가 사용자의 도면 위에서 결합되고, 결과는 제품 순위가 아니라 **가능한 후보·막히는 이유·다음에 재야 할 것**이다. [IKEA의 주방 계획 도구](https://www.ikea.com/de/en/customer-service/knowledge/articles/f4aa1b4f-d00d-4413-92ad-fa12de7d0977.html)도 방 치수를 넣고 가구·가전을 배치하는 흐름을 제공하므로, 살림랩은 특정 모델의 문 개방·반입·사용·전기 정보까지 연결하는 답을 검증해야 한다.

## 첫 검증

냉장고 구매 또는 이사를 앞둔 5명에게 실측 치수 또는 실제 주방 사진을 받아 같은 모델을 현재 상세 페이지와 시범 도면에서 각각 판단하게 한다. **① 놓을 수 있는지, ② 문과 통로가 충돌하는지, ③ 아직 확인할 값이 무엇인지**를 정확히 말하는지 확인한다. 현장 시공 결과가 나오면 시범 판정과 대조한다. 시범 단계에서 실제 설치 가능성을 보증하지 않는다.
