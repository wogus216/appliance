# 살림랩: 현재 로컬 평가에 따른 콘텐츠 발전안

상태: 2026-11-02 사용자 승인 1차 A-C 로컬 구현·검증 완료. 앞선 메타·분류 중심 초안을 대체한다.
기준일: 2026-11-02.
평가 근거: [로컬 평가 보고서](../../../research/evidence/2026-11-02/local-content-strategy-audit.md).

## 목적과 확인된 방향

장기 목표는 살림 전반으로 확장하는 것이며 첫 우선순위는 AdSense 심사 준비다. 현재 로컬의 실제 콘텐츠·기능 평가를 기준으로 한다. 사용자는 실견적 취재·수집 사업으로 확장하고 싶어 하지 않으며 제조사 회신도 필수 발행 조건으로 두지 않는다.

공개 제품 34개·카테고리 12개·비교/해설 20편·도구 8개와 기저귀 사전 6항목을 활용한다. 기존 Next.js 16 / React 19 정적 내보내기 구조를 유지한다.

아래 방향과 1차 A-C 범위는 로컬 평가 후 사용자가 승인했다. 새 원고·분야 확장은 후속 제안이다.

> 공식 자료를 우리 집의 공간·사용 방식·관리할 일과 대조해 무엇을 고르고 무엇을 보류할지 알려주는 살림 정보 사이트.

## 왜 우선순위를 바꾸는가

칸 전환에서 포기하는 용도, 코스별 적재 용량, 자동화 뒤에 남는 관리 등 자체 해석은 이미 있다. 반면 블로그에서 고친 판단이 제품 상세에는 남아 있고, 가이드가 기존 글·도구를 이름만 언급하는 경우가 있다. 메타·분류만 정리한 앞선 초안은 이 신뢰와 연결 문제를 충분히 다루지 못했다.

제품·생활 분야를 한꺼번에 확대하면 유지 범위가 늘어난다. 실견적·제조사 답변 중심 접근은 사용자 방향과 맞지 않는다. 기존 분석의 일관성과 실생활 과제 완결성을 먼저 개선하는 접근을 권고한다.

## 실행 순서

1. 아래 첫 작업 A~C: 기존 판단 불일치 수정, 세 가지 독자 경로 완성, 실제 제공 범위에 맞는 설명.
2. 새 원고 후보 ‘자동 관리 가전, 사람에게 남는 일은 무엇인가?’를 별도 조사·설계.
3. 세탁 표시·청소도구·생활용품 포장 등 인접한 살림 주제로 한 분야씩 확장.

이번 승인 대상으로 제안하는 구현 범위는 1번이다. 2~3번의 새 원고 발행·분야 확장은 포함하지 않는다.

## 첫 작업 A: 구매·사용 판단 일치

확인한 여섯 문제를 우선 수정한다.

- RF85: 본체 높이 1,853mm를 설치장 최소 높이로 단정하지 않는다. 상부 여유·수평 조절을 별도 미확인으로 설명하고 높이 충족을 설치 승인으로 쓰지 않는다.
- TP07: 하루 사용시간에 필터 수명을 반비례시킨 6개월·연 158,000원 예측을 상세에서도 제거한다. 확인한 가격·권장 조건과 잔여 수명 안내를 유지한다.
- DV17: 단독 설치와 직렬 그림의 상부 간격을 구분한다. 1,993~2,117mm 공간으로 직렬 설치를 승인하지 않는다. 2,118mm 충족도 키트·배수·전원·현장 조건을 충족했다는 뜻이 아니다.
- QCY HT08: 최대 통화시간 산술을 실제 회의 일정 보장으로 바꾸지 않는다. 공개 지연값의 조건을 모르면 게임 적합성을 단정하지 않는다.
- CHPI-7400N: 36개월 지출과 소유권 이전 시점을 함께 설명한다. 기간 말 상태가 다른 구매·렌탈을 같은 소유 비용으로 비교하지 않는다.
- 위닉스: 현재 공식 지원 근거를 확인한 뒤 서비스 번호를 공통 데이터로 통일한다. 확인되지 않으면 임의로 고르지 않고 공식 고객지원 링크를 안내한다.

이어 공개 제품 34개의 총평·상세·관련 블로그·해당 도구의 핵심 판단을 대조한다. 전 문단 재작성·모든 외부 자료 재수집으로 확대하지 않는다. 설치 치수·여유, 코스·운전 조건, 비용 기간·누락 항목, 관리 주기, 시험값·생활 추정 구분을 점검한다. 발견된 같은 유형 모순은 근거가 있는 작은 수정으로 해결하고 결과를 기록한다. 새 가격·성능·안전 주장은 공식 근거를 별도 확인한다.

## 첫 작업 B: 세 가지 생활 과제의 경로 완성

새 URL·계산 기능 없이 기존 콘텐츠와 도구를 연결한다.

| 독자 과제 | 읽을 것 | 바로 할 일 | 완료 시 남는 것 |
|---|---|---|---|
| 냉장고를 우리 집에 들일 수 있나 | 냉장고 카테고리 → 칸 배분·설치 비교 / RF85·T873 상세 | 해당 모델 설치 확인표 | 부족한 치수·미확인 조건·상담용 확인표 |
| 많은 빨래에 콤보와 분리형 중 무엇이 맞나 | 세탁기·건조기 카테고리 → 일체형/분리형 해설 / WF24·WD25·DV17 상세 | 지원 모델 설치 확인·관리 일정표 | 나눌 빨래·설치 보류 조건·다음 확인일 |
| 로봇청소기가 있어도 내가 할 청소는 무엇인가 | 로봇청소기 카테고리 → 기존 비교·설치 글 / S8·Qrevo 상세 | 기술·관리 카드 → 일정표 | 자동 처리되지 않는 작업·확인 상태·내가 정한 관리일 |

카테고리 상단에 가이드 바로가기를 두고 관련 절에 문맥에 맞는 기존 글·도구 링크를 넣는다. 제품 목록은 보존한다. 모든 카테고리에 똑같은 링크 묶음을 채우지 않는다. 식기세척기 가이드의 제목뿐인 블로그 언급도 실제 링크로 고친다.

지원 모델을 정확히 연결한다. 자동 날짜 근거가 없는 항목은 직접 날짜를 정하는 한계를 유지한다. 새 저장 포맷·계정·알림은 추가하지 않으며 기존 기록을 수정·삭제하지 않는다. 설치 가능·실제 요금·자동 관리 완료로 오해할 판정을 추가하지 않는다.

## 첫 작업 C: 공개 약속과 페이지 역할

- 공통 설명·소개 첫 문단을 홈의 실제 생활 과제와 맞춘다. 에러코드, 구매·설치·관리 분석, 생활용품 사전을 소개하되 아직 없는 콘텐츠를 제공한다고 쓰지 않는다.
- 카테고리 제목·메타는 현재 가이드 범위에 맞춘다. 이동식 TV 일부 모델·TP07/HP09 분석을 전체 시장 추천처럼 약속하지 않는다. 기존 URL·canonical 유지.
- 블로그 카드의 출처 수·글자 수 표시는 제거하고 질문·요약·종류·검수일·본문 출처는 보존한다. 전체 블로그 주제 분류 개편은 제외한다.
- 자동 조합 비교는 현재 noindex·광고 제외 유지. 브랜드 전면 재작성, 성분 사전 개편, 광고 영역 변경은 제외한다.
- 글자 수 하한을 Google 승인 요건처럼 적은 낡은 주석은 정정한다. 내부 누락 검사 자체는 보존한다.

## 이후 넣을 원고와 확장 기준

다음 원고 후보 ‘자동 관리 가전, 사람에게 남는 일은 무엇인가?’는 공식 관리 자료를 확보한 로봇청소기·정수기·건조기·식기세척기 모델을 비교한다. 자동 처리/직접 할 일/매회·알림 시 등 관리 조건/부품 접근 공간/확인한 소모품·미확인 비용/구매를 보류할 생활 조건을 다룬다. 근거 없는 절약 시간·연간 총비용·자동화 순위는 만들지 않는다. 조사·작성은 첫 작업 범위 밖이다.

다음 확장 후보는 세탁 표시와 건조 가능 여부, 청소도구 선택·손질, 기저귀 포장·광고 읽기다. 제품·물질명 목록보다 독자가 수행할 판단 하나를 중심으로 좁게 조사한다.

## 완료 조건과 검증

1. 확인된 여섯 문제와 공개 제품 34개 판단 대조 결과를 근거·수정·한계로 기록한다. 미확인을 추정으로 채우지 않는다.
2. 세 경로를 실제 클릭해 해당 지원 모델의 확인표 또는 관리일 결과에 도달한다. 원래 기능의 한계를 넘는 판정 금지.
3. 추가 링크·앵커가 실제 대상에 도달하며 기존 URL·canonical·noindex·광고 경계를 보존한다.
4. 변경 파일 lint, 관련 판단·링크 회귀 검사, 프로젝트 필수 검사·정적 빌드 수행. 모든 문장을 문자열 테스트로 고정하지 않는다.
5. Aside 390px·1440px에서 변경 면·세 경로·키보드·가로 넘침 확인. 기존 저장 데이터 보존 확인.
6. 실제 본문 변경 경로만 수정 이력에 기록. 재조사하지 않은 가격·원문 확인일은 갱신하지 않는다.
7. 결과는 로컬 완료본과 배포 대기 목록. 커밋·푸시·운영 배포·외부 문의·AdSense 신청은 이번 승인 범위가 아니다.

## 구현자에게 맡기는 결정

관련 링크를 가이드 타입에 추가할지 별도 매핑으로 둘지, 공용 링크 컴포넌트 여부, 기존 Tailwind 안의 간격·줄바꿈은 구현자가 정한다. 새 패키지·전면 디자인 교체·새 클라이언트 상태는 필요하지 않다. 사실 수정은 기존 근거를 우선 쓰고 현재성이 필요한 연락처는 공식 자료로 검증한다.

## 정책과 평가의 한계

실제 심사 결과·거절 이유는 계정에서 확인해야 한다. 이 설계는 자체 편집 계획이며 승인 확률·날짜를 제시하지 않는다. 글 수·글자 수·출처 수·직접 실측·제조사 회신을 일률적 승인 조건으로 사용하지 않는다.

- [AdSense 자격 요건](https://support.google.com/adsense/answer/9724?hl=ko)

## 설계 검토

로컬 평가 후 작성한 이 개정안을 신규 독립 검토자가 읽고 “nothing important left”라고 보고했다. 계획 수립을 막는 미결 질문이 없다는 뜻이며, 사용자 승인·Google 정책 심사·구현 검증은 아니다. 이전 초안의 검토를 재사용하지 않았다.
