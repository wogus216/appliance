# Guide visual readability implementation plan

> Use superpowers:executing-plans. 사용자가 사진·도식·요약표를 직접 요청했다. 기존 로컬 작업을 보존하고 구현한다.

**Goal:** 가이드에서 긴 본문을 읽기 전, 볼 곳·판단·다음 행동을 사진/표/도식으로 이해한다.
**Architecture:** BlogPost의 선택적 visualSummary와 공용 서버 컴포넌트. 제품 비교표와 별개인 3열 행동 요약표 및 3갈래 분류 도식. 기존 4개 가이드에 적용하고 다른 글은 보존한다. 새 상태·패키지·AI 판독 기능 없음.
**Design:** 현재 읽기 화면/폰트/색을 유지한다. 제목→짧은 핵심→요약표→설명 사진/분기 도식→긴 근거. 모바일3열 표의 내용은 짧게, 각 열을 가로 스크롤 없이 읽도록 구성. 가상 사진에 실제 브랜드 라벨·공식 세탁기호·검증 결과를 넣지 않는다. 생성 사진은 캡션에서 설명용 AI 이미지로 명시.

## Scope and review focus
- 최근 기저귀/세탁 가이드: 설명용 사진 각1장, 요약표, 판단 도식. 기존 설치/점검 가이드: 요약표·판단 도식. 기저귀는 기존 성분 사전 도식으로 이어지는 링크 유지.
- 새 시각 자료는 기존 원고/공식 근거를 요약한다. 원문에 없던 안전 허용·치수·온도·코드 공통 절차를 만들지 않는다.
- 세탁 허용≠건조 허용, 건조 후보≠코스 승인, 형광증백제 안감 범위, 물통형≠급배수형, 에러별 중단/자가점검 구별.
- 이미지 대체텍스트/캡션, HTML table th scope/caption, 텍스트로 읽히는 분기, 390/1440px 가독성과 가로 넘침, 사진이 실제 시험/시판품처럼 보이지 않는지.
