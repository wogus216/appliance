# Category visual overviews implementation plan

> Use superpowers:executing-plans. 사용자가 우선순위1의 네 카테고리 시각 정리를 승인했다.

**Goal:** 냉장고/세탁기/건조기/로봇청소기의 구매 조건을 제품 목록보다 먼저 표·설치/관리 순서 도식으로 이해하고 기존 모델 도구로 이동한다.
**Architecture:** 기존 GuideVisualSummary를 재사용한다. 공유 데이터 타입을 types/guide-visual.ts로 옮겨 blog는 재수출하고 category는 참조한다. 선택적 sequence 레이아웃·문맥 링크·본문 목적지를 더하며 기존 블로그4개의 분기 레이아웃은 보존한다. 새 의존성·상태·계산기·사진 생성 없음.
**Design:** 기존 폰트/색/표 유지. 네 페이지에서만 짧은 도입→요약표→설치/관리 확인 도식→실제 도구 링크→제품 목록→긴 선택 근거. 기존 guide-N/buying-guide 앵커 보존. 모바일에서 표 가로 스크롤 없음. 자료 확인일은 그대로 두고 해당 네 페이지의 본문 편집일을 구분한다.

## Scope / review focus
- 기존 네 원고의 사실만 요약. 새 가격·치수·설치/안전 허가 없음.
- 냉장고 합계L/칸별 용량·본체/설치/문 열림 구분. 세탁 코스 상한/의류 분류/동시 처리의 가정 구분. DV17 단독/직렬 및 고정일수/매회/상태 기준 구분. 로봇 물통형/급배수 구성과 자동 처리/남는 관리 구분.
- 순서 도식은 순서대로, 분기 도식은 갈래 선택으로 안내. 블로그 기존 분기와 본문 바로가기 보존. 모바일/키보드/날짜/실제 모델 링크 확인.
