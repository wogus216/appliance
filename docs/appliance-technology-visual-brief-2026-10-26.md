# 가전 기술을 보여 주는 시각 요소 — 2026-10-26

## 목적

제품 상세의 `핵심 기술` 한 줄과 기능 목록을 **부품·흐름·생활 결과**로 연결한다. 사용자는 “이 기술이 어디서 무엇을 하고, 나에게 어떤 편의와 관리 부담을 만드는가?”를 볼 수 있어야 한다. 확인된 부품 이름만 실제 모델의 그림에 넣고, 내부 구조를 확인하지 못하면 **원리 도식**이라고 표시한다.

## 첫 화면: CHPI-7400N 얼음정수기 물길 지도

[코웨이 CHPI-7400N 공식 설명서](https://www.coway.com/core/product/fmanual/download/274)는 정수 방식, 두 필터, 정수 직수식, 냉수 1L 칠링존, 얼음 저장고 0.74kg, 순간온수 방식과 온수 정격 2,950W를 적는다. [공식 제품 페이지](https://www.coway.com/product/detail?prdno=1148)는 제빙량을 특정 시험 조건의 자사 결과로 제시한다. 사이트에는 공단 신고 월 12.17kWh도 이미 대조돼 있다. 서로 다른 숫자의 의미와 시험 범위를 섞지 않는다.

```text
수도 ── 나노트랩 필터 ── 플러스이노센스 필터 ──┬─ 정수: 직수식
                                                  ├─ 냉수: 1L 칠링존
                                                  ├─ 얼음: 0.74kg 저장고
                                                  └─ 온수: 순간 가열(CHPI 모델)
```

그림에서 `냉수`를 누르면 **“정수는 직수지만 냉수는 칠링존에 담긴다. 1L는 저장부의 규격이며 한 번에 뽑을 수 있는 양과 같지 않을 수 있다”**고 설명한다. `얼음`을 누르면 저장고 관리와 자사 시험 제빙량의 조건을 보여 준다. `온수`를 누르면 **2,950W는 가열할 때의 정격 전력이고 한 달 사용량이 아님**을 보여 준다. 별도 전기량 카드에는 공단 신고 월 12.17kWh를 시험 조건의 값으로 표시한다.

히트펌프 건조의 일반 원리는 [ENERGY STAR의 설명](https://www.energystar.gov/products/clothes_dryers)에 근거할 수 있다. 다만 특정 모델의 히터 보조·응축수 처리·필터 접근 방식은 해당 모델의 설명서와 따로 맞춘 뒤에만 제품 페이지에 표시한다.

## 한 화면의 정보 규칙

각 핫스팟은 다음 다섯 항목 중 확인한 것만 담는다.

1. **부품/기술:** 해당 모델에 실제 적용되는 이름.
2. **하는 일:** 물·공기·열·전기가 어디로 움직이는지.
3. **생활 효과:** 사용자가 무엇을 덜 하거나 새로 해야 하는지.
4. **관리·한계:** 필터·물통·청소·소음·전력의 확인된 조건.
5. **출처:** 제조사 설명서의 해당 쪽 또는 독립 시험의 정확한 모델 범위.

단순한 2D SVG와 짧은 단계 전환으로 시작한다. 기존 사이트의 `LayerDiagram`은 SVG와 텍스트 설명을 함께 제공하므로 접근성 구현의 참고가 된다. 애니메이션은 물길·열 흐름을 이해시키는 데만 쓰고, 사용자가 동작을 멈출 수 있게 한다. 그림 아래에 같은 내용을 텍스트로 제공한다.

## 데이터·표현 경계

- 현재 카탈로그의 `coreTechnology`와 `features`는 자유 문장이다. 이 문자열만 파싱해 내부 부품 그림을 자동 생성하지 않는다. 모델별 공식 근거와 `components`, `flows`, `maintenance`, `evidence`를 구조화한다.
- 공식 문서에 내부 배관·공기 통로의 위치가 없다면 기계 내부의 실제 배치처럼 그리지 않는다. 원리만 보여 주고 `원리 도식, 실제 내부 배치와 다를 수 있음`이라고 표시한다.
- 기능을 시각화했다고 제거율, 절전율, 저소음, 고장률을 증명한 것으로 쓰지 않는다. 성능 수치는 정확한 모델과 시험 조건이 확인될 때만 별도 배지로 보여 준다.
- [가상 공간 기능](virtual-appliance-room-feature-brief-2026-10-26.md)과 연결해, `제품 안에서 무슨 일이 일어나는지`와 `집의 어디에 둘 수 있는지`를 같은 모델 ID로 이어 준다.

## 검증

정수기를 비교 중인 사용자 5명에게 기존 기능 목록과 물길 지도를 각각 보여 준다. **① 직수와 저장부의 차이, ② 관리해야 할 부품, ③ 2,950W와 12.17kWh/월의 차이**를 올바르게 설명할 수 있는지 확인한다. 이해가 늘지 않으면 그래픽의 형태보다 문구와 정보 순서를 수정한다.
