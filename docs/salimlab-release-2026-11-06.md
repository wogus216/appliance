# 2026-11-06 배포

11월 1~4일에 로컬에서 완료한 생활 도구·콘텐츠·제품 사진 변경을 함께 배포한다.

- 설치 상담 요약, 제품별 상담 기록과 수첩 연결, 실측 전력 기록 비교, 정수기 계약 조건 보관 및 비용 비교를 보강했다.
- 세탁표시·기저귀 포장·자동 가전 관리·정수기 계약 날짜 해설 4편을 추가하고 카테고리 12개의 시각 요약, 소재·브랜드·제품·도구 사이 연결을 정리했다.
- 제품 사진과 표시 방식을 교정하고 원자료 확인일과 문서 편집일을 구분했다. 세부 작업 근거는 research/evidence/2026-11-01~04에 있다.
- 기존 SITE_REVISIONS의 미배포 작업일 항목을 실제 배포일인 2026-11-06으로 통합했다. 원자료 확인일과 새 글 자체 작성일은 유지했다.
