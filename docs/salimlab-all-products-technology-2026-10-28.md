# 공개 제품 34개의 기술·관리 지도

작성일: 2026-10-28. ‘제품마다’ 적용 요청에 따라 기존 4개에 30개를 더했다. 현재 공개 중인 12개 품목·34개 제품 모두에서 정확 모델의 기능·사용 조건·관리 항목을 확인할 수 있다. 로컬 구현과 검증 결과를 기록하며, 운영 배포는 아직 하지 않았다.

## 사용 흐름

- 제품 상세 목차의 **기술·관리**에서 시작한다. 기능·부품을 누르면 원리 설명, 생활에서의 의미, 챙길 관리, 해석 범위와 공식 근거가 바뀐다.
- 설명서와 내 관리 내역을 확인해 체크하고, 현재 선택 설명과 전체 관리 카드를 복사하거나 텍스트로 저장한다. 복사 실패 시 직접 복사할 텍스트를 제공한다.
- 선택 항목은 `?tech=항목ID#technology-map` 주소로 다시 연다. 잘못된 항목 주소는 지원하지 않는다고 표시한다. 체크 상태는 주소·서버에 저장하지 않고 새로고침과 모델 이동 시 비운다.
- 홈의 기존 네 제품 진입점을 유지하고 **다른 30개 제품의 기술·관리 지도 찾기**를 펼쳐 나머지 제품을 고른다. 기본 HTML에 모든 진입 링크가 있다.
- JavaScript 없이도 제품별 기본 설명·관리 항목·공식 원문을 읽을 수 있다.

정수기 CHPI-7400N의 물길 분기·전력 설명은 기존 별도 화면을 유지한다. 나머지 33개는 공통 화면에 모델별 작성 데이터를 전달한다. 범용 연결선은 기능·관리 영역을 묶는 표시이며 실제 내부 구조·배관·전기 회로·동작 순서를 재현하지 않는다.

## 자료와 구현

새 30개 모델의 공식 자료 57건을 재확인했다. [근거 대조 기록](../research/evidence/2026-10-28/all-products-technology-source-check.md)과 [원문 수신 기록](../research/evidence/2026-10-28/all-products-technology-sources.json)에 모델·절·URL·확인일·수신 결과를 보관한다. 파일을 받은 자료에는 SHA-256을 남겼고 웹 도구로 확인한 Sony 자료에는 파일 해시가 없음을 표시했다.

- `src/lib/data/catalog-technology/household.ts`: 생활가전 21개 추가
- `src/lib/data/catalog-technology/media.ts`: TV·이어폰 9개 추가
- `src/lib/data/catalog-technology/sources.ts`: 새 30개 모델의 출처
- `src/lib/data/catalog-technology/define.ts`: 명시적으로 작성한 모델별 문장·관리 항목 조립
- `src/lib/data/appliance-technology.ts`: 기존 3개와 추가 30개의 정확 모델 등록
- `src/components/detail/appliance-technology.tsx`: 공통 선택·확인·복사·저장 화면
- `src/app/page.tsx`: 전체 제품 진입 목록

카탈로그 특징 문자열을 파싱해서 주기나 내부 부품을 생성하지 않는다. 같은 브랜드에서도 기능 유무·세척 허용·교체 주기·기기 호환 조건을 따로 작성했다. LG R5·TCL 등 고정 관리 주기가 확인되지 않은 항목은 미확인으로 표시했다. 이어폰과 TV에는 사용자가 판단할 연결·입력·충전 조건을 관리와 함께 담았다.

## 검증

- 전체 테스트 **31개 파일·2,129개 통과**. 이번 추가 검사 73개는 공개 전체 모델의 단일 지도·정적 본문·근거 연결과 모델별 차이를 확인한다.
- TypeScript·변경 코드 ESLint·공백 검사 통과.
- Next.js 정적 빌드 통과. 기존 **158개 페이지**를 유지한다.
- 실제 정적 산출물에서 **브라우저 검사 1,559개 통과**. 데스크톱 1280px·모바일 390px의 68개 제품 화면에서 220개 항목 전환, 정확 모델 설명·선택 상태·복사, 주소 복원·체크 초기화, 미지원 주소·키보드 복구, canonical과 가로 넘침을 확인했다.
- 12개 품목과 별도 정수기 화면을 포함한 13개 표본에서 다운로드 내용과 복사 실패 대안을 확인했다. 홈의 전체 34개 진입 링크·30개 펼치기·제품 이동과 체크 초기화를 확인했다.
- JavaScript를 끈 브라우저에서도 34개 제품의 기본 설명·확인표·원문을 확인했다. TV·이어폰·냉장고·에어컨·정수기·로봇청소기의 데스크톱·모바일 화면을 캡처하고 대표 화면의 글자·조작 영역을 검토했다.

[브라우저 검사 결과](../research/evidence/2026-10-28/all-products-technology-browser-result.json)에 실행 환경과 집계값을 남겼다. 자동 검사의 로딩 직후 클릭·주소 복원 대기는 하이드레이션 이후 상태를 확인하도록 보완했다.
