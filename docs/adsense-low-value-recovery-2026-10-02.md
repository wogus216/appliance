# AdSense ‘가치없는 콘텐츠’ 재심사 준비 현황 — 2026-10-02

`40% → 90%`는 통계나 승인 확률이 아니라 작업 우선순위를 나타내는 주관적 표현이다. Google의 심사 결과를 대신할 수 없다. 이 문서는 실제 변경·검사와 남은 조건을 분리한다.

## 이번 회차에서 확인한 것

- 코웨이 `CHPI-7400N`의 6개 ‘오류코드’는 공식 설명서의 표시 코드가 아니었다. 제품 페이지에 설명서 인쇄 35–37쪽의 증상별 점검 순서를 실었다. [대조 기록](../research/evidence/2026-10-02/coway-winix-troubleshooting-audit.md).
- 위닉스 `DN2H160-IWK`의 `E1·E2·E3·CF` 진단은 모델 페이지가 연결한 DN2 계열 설명서에서 확인되지 않았다. `dF`는 고장 코드가 아니라 자동 제상 표시다. 제품 페이지의 모드·필터·청정 기능·사용 조건도 원문에 맞춰 수정했다. 같은 [대조 기록](../research/evidence/2026-10-02/coway-winix-troubleshooting-audit.md)에 범위를 적었다.
- 근거 없는 `/error-codes/Coway`와 `/error-codes/Winix`는 라이브에서 404, 사이트맵에서 제외됐다. 두 제품 페이지는 200이며 새 설명이 렌더된다.
- 제품 제목의 ‘리뷰’를 ‘자료 분석’으로 바꾸고, 제품 상단·목록 카드에 가격 조사일을 표시했다. 직접 사용·측정하지 않는다는 편집 원칙과 맞추기 위한 조치다.
- 최근 90일 Search Console 노출 상위 제품인 TCL `TAC-08CSD/TPH11I`는 한국에너지공단의 정확한 실내기·실외기 조합 신고값을 근거로 냉방비 단정을 수정했다. [효율 자료 대조](../research/evidence/2026-10-02/tcl-08csd-efficiency-check.md).

## 재심사 전 남은 조건

1. **상위 유입 문서와 남은 오류코드 허브의 모델 적용 범위 검수.** 삼성 E5·LG FE·Haier CTH06QBW부터 제조사 원문과 본문을 대조하고, 확인되지 않은 진단은 제품별 증상 안내로 옮기거나 색인에서 뺀다. 조회수만을 이유로 근거 없는 내용을 남기지 않는다.
2. **색인 대상의 독자적 판단 강화.** 제품 25·블로그 19·브랜드 13·카테고리 12를 재고, 같은 사양의 반복이 아닌 설치·사용 조건·시험 범위·비용 조건을 모델별로 설명하는지 표본 검수한다. 품질 게이트 통과나 글자 수만으로 완료 처리하지 않는다.
3. **재크롤 확인.** 배포일 이후 Google의 마지막 크롤 날짜가 바뀐 URL만 전후 상태를 비교한다. 404로 전환한 두 허브가 검색 결과에서 사라지는 데는 시간이 걸릴 수 있다. 사이트맵 재제출 여부와 상태도 별도로 확인한다.
4. **AdSense 계정 확인 및 재심사.** 사용자가 로그인한 AdSense에서 실제 사이트 상태와 재심사 버튼을 확인해야 한다. 이 문서 시점에는 재심사를 요청하지 않았고, 승인 가능성을 수치로 말할 근거가 없다.
