# AdSense ‘가치없는 콘텐츠’ 재심사 준비 현황 — 2026-10-02

`40% → 90%`는 통계나 승인 확률이 아니라 작업 우선순위를 나타내는 주관적 표현이다. Google의 심사 결과를 대신할 수 없다. 이 문서는 실제 변경·검사와 남은 조건을 분리한다.

## 이번 회차에서 확인한 것

- 코웨이 `CHPI-7400N`의 6개 ‘오류코드’는 공식 설명서의 표시 코드가 아니었다. 제품 페이지에 설명서 인쇄 35–37쪽의 증상별 점검 순서를 실었다. [대조 기록](../research/evidence/2026-10-02/coway-winix-troubleshooting-audit.md).
- 위닉스 `DN2H160-IWK`의 `E1·E2·E3·CF` 진단은 모델 페이지가 연결한 DN2 계열 설명서에서 확인되지 않았다. `dF`는 고장 코드가 아니라 자동 제상 표시다. 제품 페이지의 모드·필터·청정 기능·사용 조건도 원문에 맞춰 수정했다. 같은 [대조 기록](../research/evidence/2026-10-02/coway-winix-troubleshooting-audit.md)에 범위를 적었다.
- 근거 없는 `/error-codes/Coway`와 `/error-codes/Winix`는 라이브에서 404, 사이트맵에서 제외됐다. 두 제품 페이지는 200이며 새 설명이 렌더된다.
- 다이슨 TP07·HP09에 게시됐던 12개 코드 항목도 [공식 한국어 설명서 대조](../research/evidence/2026-10-02/dyson-error-code-source-check.md)에서 확인되지 않아 제거했다. 필터 수명 확인·교체·초기화는 제품별 분석에 남겼다. 라이브 `/error-codes/Dyson`은 404다.
- 제품 제목의 ‘리뷰’를 ‘자료 분석’으로 바꾸고, 제품 상단·목록 카드에 가격 조사일을 표시했다. 직접 사용·측정하지 않는다는 편집 원칙과 맞추기 위한 조치다.
- 최근 90일 Search Console 노출 상위 제품인 TCL `TAC-08CSD/TPH11I`는 한국에너지공단의 정확한 실내기·실외기 조합 신고값을 근거로 냉방비 단정을 수정했다. [효율 자료 대조](../research/evidence/2026-10-02/tcl-08csd-efficiency-check.md).
- 샤오미 공기청정기 4는 자체 고효율 필터를 H13으로 잘못 소개하고 필터 교체 뒤 수동 초기화를 지시하던 문구를 고쳤다. 정확한 모델의 E1~E6 코드 대응 근거는 확인되지 않아 제거했다. [대조 기록](../research/evidence/2026-10-02/xiaomi-air-purifier-4-code-and-filter-audit.md).
- 쿠쿠 CDW-A0611TW 공식 설명서 인쇄 25쪽의 코드표와 대조해 E2를 빼고 E4를 ‘누수 및 기능점검’으로 바로잡았다. 제품·비교 글의 ‘물탱크 급수’ 주장은 설명서의 급수호스 설치 안내와 맞지 않아 제거했다. [대조 기록](../research/evidence/2026-10-02/cuckoo-cdw-a0611tw-manual-code-install-audit.md).
- 로보락 S8 Pro Ultra·Qrevo Curv의 정확한 모델별 고객지원 문서를 찾아, 확인되지 않은 다섯 코드 진단을 제거했다. Qrevo Curv의 DuoDivide를 물걸레로 잘못 부른 설명과 본체 치수·문턱 조건도 고쳤다. [대조 기록](../research/evidence/2026-10-02/roborock-model-error-source-audit.md).

## 현재 측정값과 해석

- 코웨이·위닉스 배포 후 사이트맵은 **97 URL**이었다. 다이슨 근거 없는 허브를 제거한 현재 라이브 사이트맵은 **96 URL**이다. 제품 25, 블로그 19, 브랜드 13, 카테고리 12는 유지된다. 비교 조합 44개는 정적 생성되지만 이미 모두 `noindex`이며 사이트맵에 없다.
- 샤오미·쿠쿠·로보락 수정 후 **로컬 빌드**의 사이트맵은 **98 URL**이다. 샤오미 오류 허브 1개가 빠지고, 공식 모델 자료가 추가되면서 쿠쿠 브랜드 1개와 쿠쿠·로보락 S8 제품 2개가 색인 자격을 얻었다. 이 수치는 배포 전 빌드 결과이며 라이브 96 URL과 구분한다. 색인 자격 통과만으로 독자적 품질이나 Google 색인을 보장하지 않는다.
- 다이슨 변경 **이전** Search Console URL 검사: **색인 1/97**, 발견·미색인 39, 크롤·미색인 34, Google이 모름 23. 로컬 스냅샷은 `.audit/gsc/sc-domain_salimlab.kr/2026-10-02.json`에 있다. 코웨이·위닉스 제품은 크롤 이력이 없으며 새 Haier F25도 Google이 아직 모른다. 오늘의 콘텐츠 개선 효과로 숫자를 해석하면 안 된다.
- 최근 90일 검색 실적(2026-07-02~09-29): 노출 132, 클릭 1, 노출된 URL 17개. 마지막 노출은 2026-09-22. 상위 URL은 TCL TAC-08CSD 제품(24회), 홈(21회), 삼성 E5(14회), Haier CTH06QBW(12회), LG FE(10회)다. 노출은 검색 수요의 단서일 뿐 콘텐츠 정확성의 증거가 아니다.
- `f7fe832`의 GitHub Actions 배포는 성공했고, 코웨이·위닉스 제품 200, 두 잘못된 허브 404, 라이브 사이트맵 제외를 확인했다. TCL 수정분은 뒤따르는 배포에서 별도로 확인한다.

## 재심사 전 남은 조건

1. **상위 유입 문서와 남은 오류코드 허브의 모델 적용 범위 검수.** 샤오미·쿠쿠·로보락 검수 뒤 로컬 빌드에 남은 브랜드 허브는 8개다. 삼성 E5·LG FE·Haier CTH06QBW부터 제조사 원문과 본문을 대조하고, 확인되지 않은 진단은 제품별 증상 안내로 옮기거나 색인에서 뺀다. 조회수만을 이유로 근거 없는 내용을 남기지 않는다.
2. **색인 대상의 독자적 판단 강화.** 제품 25·블로그 19·브랜드 13·카테고리 12를 재고, 같은 사양의 반복이 아닌 설치·사용 조건·시험 범위·비용 조건을 모델별로 설명하는지 표본 검수한다. 품질 게이트 통과나 글자 수만으로 완료 처리하지 않는다.
3. **재크롤 확인.** 배포일 이후 Google의 마지막 크롤 날짜가 바뀐 URL만 전후 상태를 비교한다. 404로 전환한 두 허브가 검색 결과에서 사라지는 데는 시간이 걸릴 수 있다. 사이트맵 재제출 여부와 상태도 별도로 확인한다.
4. **AdSense 계정 확인 및 재심사.** 사용자가 로그인한 AdSense에서 실제 사이트 상태와 재심사 버튼을 확인해야 한다. 이 문서 시점에는 재심사를 요청하지 않았고, 승인 가능성을 수치로 말할 근거가 없다.

검증 명령: `npm test -- --run`, `npm run lint`, `npx tsc --noEmit`, `npm run build`. 다이슨 수정까지 1,894개 테스트와 정적 빌드가 통과했고, TCL 라이브 제품 페이지의 공단 수치·출처·가격 조사일 표시를 확인했다. 다이슨 라이브 제품 2개는 200에 필터 안내를 표시하고, 오류코드 허브는 404·사이트맵 제외다.

샤오미·쿠쿠·로보락 후속 수정은 1,890개 테스트, ESLint, TypeScript 검사, 155개 정적 페이지 빌드가 통과했다. 로컬 사이트맵 98 URL에는 샤오미 오류 허브가 없고 쿠쿠·로보락 허브는 남는다. 이 문단의 라이브 상태는 배포 뒤 확인해 갱신한다.
