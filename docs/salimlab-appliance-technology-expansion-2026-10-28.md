# 기술 지도와 관리 카드의 다른 품목 확장

작성일: 2026-10-28. 사용자 요청에 따라 기존 CHPI-7400N 외에 세 정확 모델을 추가했다. 로컬 구현·검증 완료, 운영 배포 전이다.

기존 정수기를 포함해 4개 모델에서 기술·관리 지도를 볼 수 있다. 각각의 제품 상세 `#technology-map`에 연결하고 목차를 ‘기술·관리’로 표시한다. 홈의 해당 절에서 네 제품으로 진입한다.

## 기능과 데이터

- 세 새 모델은 같은 선택·확인표·복사·저장 화면을 재사용하고 부품·관리·출처를 모델별 레코드로 관리한다. 물길 분기와 W/kWh 설명이 있는 기존 정수기 화면은 별도 표현을 유지한다.
- 부품 선택 시 원리·생활에서의 해석·관리할 곳·자료 한계를 보여 준다. 그림은 관리 영역의 연결도이며, 내부 배관·공기·냉매 회로나 부품 위치를 재현하지 않는다.
- 선택한 부품은 `?tech=부품ID#technology-map` 주소로 복원한다. 미지원 항목은 안내를 띄우며 기본 항목으로 대체하지 않는다.
- 체크는 내 관리 내역 확인 표시다. 모델·선택한 설명·관리 항목·안전 안내·원문을 복사하거나 텍스트로 저장한다. 복사 실패 시 직접 복사할 기록을 제공한다.
- 체크 상태는 주소·서버에 저장하지 않고 새로고침 시 비운다. 제품 간 이동에서도 모델별 컴포넌트 키로 상태를 분리한다.
- 원문 URL과 위치를 항목마다 연결하고, 인쇄/절 표기와 PDF 실제 쪽을 따로 저장한다.

[공식 자료 재확인 기록](../research/evidence/2026-10-28/appliance-technology-source-check.md)에 문서별 쪽·확인 내용·해시를 남겼다. 고정 주기가 없는 항목에 날짜를 만들지 않으며, 다른 모델에 임의로 적용하지 않는다. 로보락은 공식 영문 자료 범위와 국내 동봉 설명서 우선 조건을 표시한다.

## 구현 위치

- `src/lib/appliance-technology.ts`: 부품 선택·주소·근거 링크·기록
- `src/lib/data/appliance-technology.ts`: 세 모델의 구조화한 기능·관리·출처
- `src/components/detail/appliance-technology.tsx`: 모델 공통 화면
- 기존 성능 절·목차·홈에 연결. 새 페이지·사이트맵 항목·외부 서비스는 추가하지 않았다.

## 검증

- 신규 단위 테스트 18개 통과. 정확 모델 범위, 부품 그룹과 근거 연결, 품목별 관리 기준 차이, 공유 주소·기록, 정적 HTML, 기존 정수기 보존과 미지원 제품 미표시를 확인했다.
- 전체 테스트 30개 파일·2,056개 통과.
- 변경 코드 ESLint, TypeScript, 정적 빌드 통과. 페이지 수는 기존 158개 유지.
- 데스크톱 1280px·모바일 390px에서 브라우저 검사 137개 통과. 세 모델의 모든 부품 전환·선택 상태·모델별 설명, 복사·파일 내용·복사 실패 대안, 주소 복원·체크 초기화, 키보드, 노드 글자 및 페이지 가로 넘침, 홈 진입, 기존 정수기 보존, 하이드레이션·JavaScript 오류를 확인했다.
- 생성된 정적 산출물에서도 세 모델의 부품 주소·새로고침·체크 초기화·canonical·홈 진입을 확인했다. JavaScript 없이 기본 설명·관리 항목·원문이 표시되고 브라우저 예외가 없었다.

실제 사용자가 부품과 관리 조건의 차이를 이해하는지 검증하는 작업은 남아 있다. 운영 배포 시 실제 배포일과 변경 본문 경로에 맞춰 수정일을 갱신해야 한다.
