# 냉장고 설치 전 확인표 구현 기록

작성일: 2026-10-27. [소비자 도구 기획](salimlab-consumer-utility-site-plan-2026-10-27.md)의 첫 묶음 중 세 번째 도구를 로컬 구현했다. 운영 배포와 실제 사용자 검증은 남아 있다.

## 사용자 흐름

1. 홈, 지원 제품 상세, 전기사용량 비교에서 `/tools/fridge-fit`으로 진입한다. 제품별 링크는 `?model=정확모델`을 포함한다.
2. RF85C90D1AP, T873MEE111, RS84B5061M9, S834MWW1D 중 한 모델을 선택한다.
3. 냉장고 자리 폭·높이, 문을 펼칠 구역의 폭, 뒷벽부터 맞은편 장애물까지의 거리, 반입 경로 최소 폭을 mm로 입력한다. 모르는 항목은 비워 둔다. 올바른 천 단위 쉼표와 소수 한 자리까지 지원한다.
4. 2D 평면도에서 닫힌 본체, 후면 간격을 둔 위치, 문 개방 폭·깊이 참고선, 입력한 확보 공간을 확인한다. 참고 치수보다 작은 방향은 빨간 선으로 표시한다.
5. 항목별 치수 차이·부족·미측정을 확인하고 설치 상담용 사진·질문 준비 여부를 체크한다.
6. 모델·입력값·추가 확인 항목·설명서 출처를 복사하거나 텍스트 파일로 저장한다. 복사 실패 시 직접 선택할 기록을 제공한다.

집에서 잰 값과 체크 상태는 브라우저 메모리에만 있다. 모델을 바꿀 때 집 치수는 유지하고 모델 관련 질문 체크를 비운다. 새로고침하면 모델은 주소에서 복원하지만 집 치수와 체크는 비운다. 공유 주소에도 집 치수를 포함하지 않는다.

## 원문과 계산 범위

[설명서 대조 기록](../research/evidence/2026-10-27/fridge-fit-source-check.md)에 모델별 치수·문 개방 각도·페이지·원문·재수신 해시를 남겼다. 별도 숫자 데이터는 `src/lib/data/fridge-installation.ts`가 관리한다.

- 자리 폭: 본체 폭 + 좌우 참고 간격 두 개. 좌우 수치가 고장 진단 절의 안내라는 점을 표시한다. LG는 설치 절에 좌우 수치가 없다는 점도 함께 적었다.
- 높이: 전체 본체 높이와 입력 높이의 차이만 계산한다. 상부 여유와 수평 조절 후 높이를 확인하지 않았으므로 차이가 양수여도 설치 확정으로 표시하지 않는다.
- 문 앞 공간: 개방 폭과 최소 후면 간격 + 개방 깊이를 각각 비교한다. 삼성의 서로 다른 개방 각도에서 온 폭·깊이를 하나의 점유 직사각형으로 그리지 않는다.
- 반입: 폭을 기록하지만 통과 여부를 자동 판정하지 않는다. 문 분리·높이·회전·엘리베이터는 설치팀 확인 항목이다.

입력이 비어 있으면 미측정으로, 0·음수·단위 문자·잘못된 쉼표·지원 범위 밖 숫자는 입력 오류로 남긴다. 지원하지 않는 모델 주소를 기본 모델로 대체하지 않는다. 도구는 전체 설치 가능 여부를 판정하지 않는다.

## 변경 위치

- `src/lib/fridge-fit.ts`: 입력 해석, 항목별 계산, 상담 기록
- `src/lib/data/fridge-installation.ts`: 네 모델의 구조화한 치수·원문·제약
- `src/components/tools/fridge-fit-tool.tsx`: 모델·실측 입력, 참고도, 결과, 상담 준비, 복사·저장
- `src/app/tools/fridge-fit/page.tsx`: 도구 페이지와 메타데이터
- 홈·제품 적합성 절·전기사용량 비교에 진입 링크, 사이트맵에 새 경로 연결

기존 디자인의 색·서체·폼 스타일을 따른다. 3D 합성 이미지나 드래그 가구 배치는 이번 범위에 포함하지 않는다.

## 검증

- 신규 관련 단위 테스트 21개: 측정 누락·0·문자·천 단위, 계산 경계, LG 안내 차이, 삼성 개방 각도 차이, 후면 여유 합산, 자동 반입 판정 방지, 카탈로그 정확 모델·치수 일치, 상담 기록, 정적 초기 HTML.
- 전체 테스트 28개 파일·2,022개 통과.
- 변경 코드 ESLint, TypeScript 및 정적 빌드 통과. 총 158개 페이지 생성.
- 데스크톱 1280px·모바일 390px 브라우저 검사 51개 통과: 미입력·오류·부족 표시, 모델 변경과 주소 복원, 그림의 공간 선, 복사·파일 내용·복사 실패 대안, 체크 초기화, 가로 넘침, 홈·제품 상세·전기량 도구 간 이동, 하이드레이션·JavaScript 오류 확인.
- 생성된 정적 산출물에서도 모델 주소·계산·새로고침 시 실측값 초기화, 홈·제품 상세·전기량 도구의 진입 링크, canonical·사이트맵, JavaScript 없이 기본 치수와 출처 표시를 확인했다.

운영 배포 전에 실제 배포 날짜로 본문 변경 경로의 수정일을 갱신하고 배포 화면을 확인해야 한다. 실제 구매·이사 예정자에게 측정 항목을 이해하는지, 참고도와 미확인 조건을 구별하는지 확인하는 작업도 남아 있다.
