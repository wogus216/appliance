# 삼성 세탁건조기·건조기 부품 분석: 공개 근거의 경계

조사일: 2026-09-29. 대상은 사이트에 게시된 국내 모델 `WD25DB8995BZ`와 `DV17A9720BV`다. 이 문서는 출처를 대조해 작성한 분석 원고용 메모다. 관련 해외 모델의 부품번호를 국내 모델의 실장 부품으로 옮기지 않는다.

## 1. 정확한 모델에서 확정할 수 있는 구조

| 모델 | 제조사가 확인한 사실 | 부품 분석에서의 의미 |
| --- | --- | --- |
| `WD25DB8995BZ` | [삼성 제품 사양](https://www.samsung.com/sec/support/model/WD25DB8995BZ/)은 세탁 25kg·건조 15kg, 가열 세탁 시 정격 2,100W·건조 시 정격 1,700W를 구분한다. [삼성 의류케어 가이드](https://www.samsung.com/sec/home-appliances/buying-guide/washers-and-dryers-buying-guide/)는 이 모델을 시험 각주에 명시하며 콤보 제품군의 하이브리드 히트펌프 구조를 설명한다. | 세탁 물 가열과 건조 열관리의 정격을 구분할 수 있다. 1,700W를 컴프레서 단독 소비전력이나 한 회 전력량으로 읽을 수 없다. |
| `DV17A9720BV` | [삼성 제품 사양](https://www.samsung.com/sec/support/model/DV17A9720BV/)은 건조 방식이 `인버터 히트펌프 + 히터`, 정격 소비전력이 2,400W라고 명시한다. | 히트펌프 외에 별도 가열 수단이 있는 건조기다. 운전 중 히터 투입 조건과 각 회로의 전력 분담은 이 사양으로 알 수 없다. |

두 제품의 `1,700W`와 `2,400W`는 서로 다른 용량·구성의 **정격 전력**이다. 작동 시간과 부하, 건조 종료 상태가 없는 수치로 건조 효율이나 전기요금을 서열화할 수 없다. 히트펌프가 있다는 사실도 컴프레서의 제조사·형번·냉매·속도 제어 칩을 특정하지 않는다.

## 2. 부품번호를 어디까지 연결할 수 있는가

[삼성이 작성한 `WD18DB8995BZT2` 해외 변형 서비스 부품표 사본](https://manuals.plus/m/73b8fc1505369dfb68cf4bfbd4a207089081bcac21a0ec3952dc1b1d4570f5f2)은 `DC97-24179B` 배수펌프 조립품의 규격에 `WD25DB8995BZ`를 직접 적고, 하위 모터를 `DC31-00200A`로 기록한다. 따라서 두 번호는 **국내 모델과 연결된 후보**다. 부품표의 완제품은 `WD18DB8995BZT2`이므로 국내 `WD25DB8995BZ`의 생산 개체에 실제 장착됐다는 결론은 아직 불가능하다. 이 두 항목의 출처 위치와 한계는 [`part-level-evidence.jsonl`](part-level-evidence.jsonl)에 저장했다.

같은 해외 변형 부품표에는 드럼 구동 `DC93-00236G` DD BLDC 모터, `DC31-00198A` BLDC 팬 모터, 유럽형 7인치 표시판 `DC92-03710D`도 나온다. 이 세 행의 규격에는 `WD25DB8995BZ`가 명시되지 않는다. 특히 표시판은 유럽형으로 표기되어 있다. 세 번호는 **해외 변형의 구조를 읽는 자료**로만 사용하고 국내 모델 후보 목록과 부품 수 집계에 넣지 않는다. 배수펌프 모터와 드럼 구동 모터도 서로 다른 장치이므로 혼동하지 않는다.

`DV17A9720BV`에서는 [삼성전자서비스 부품 적용 모델 표](https://www.samsungsvc.co.kr/shop/product/0000083525)가 `DC63-02526A` 3차 마이크로 필터의 호환을 정확한 모델명으로 확인한다. 상세 안내는 필요한 경우 이 필터를 열교환기 커버에 장착하도록 설명한다. 따라서 실제 제품에 이미 장착됐다고 단정할 수 없다. 공개 확인한 자료에서 `DV17A9720BV`의 컴프레서·팬 모터·히터·제어 PCB 번호는 아직 확인되지 않았다.

| 부품/회로 | `WD25DB8995BZ` | `DV17A9720BV` | 제품 분석에 쓸 수 있는 표현 |
| --- | --- | --- | --- |
| 배수펌프 | 해외 변형 부품표가 `DC97-24179B` 규격에 국내 모델명을 기재 | 모델 전용 번호 미확인 | `WD25DB8995BZ` 관련 **후보**. 실제 장착 확정 아님 |
| 배수펌프 모터 | 같은 조립품의 하위 `DC31-00200A` | 모델 전용 번호 미확인 | 펌프 하위 후보. 건조계 컴프레서나 드럼 구동 모터가 아님 |
| 드럼 구동·송풍 모터 | 해외 변형에는 각각 `DC93-00236G`·`DC31-00198A`; 국내 모델 연결 없음 | 모델 전용 번호 미확인 | 번호를 국내 제품 사양으로 게시하지 않음 |
| 컴프레서·히터·인버터 기판 | 시스템 구조만 확인, 형번 미확인 | 히트펌프+히터 방식만 확인, 형번 미확인 | 회로별 소비전력·효율·수명 판단 보류 |
| 필터 | 이 조사에서 모델별 번호 미확인 | `DC63-02526A` 선택 장착 호환 확인 | 기본 장착품이나 건조 성능 근거로 사용하지 않음 |

## 3. 독자 분석을 만들 수 있는 다음 실증

1. **모델·로트 확인:** 완제품 명판 전체 코드와 제조연월, 펌웨어를 원본 사진으로 보관한다. 삼성 서비스 부품표의 적용 모델·대체 이력 또는 직접 촬영한 부품 라벨을 이 정보에 연결한다. 같은 프로젝트 코드와 비슷한 외형만으로 부품 동일성을 판정하지 않는다.
2. **회로 역할과 실장 대조:** 배수펌프, 드럼 구동, 송풍, 컴프레서, 가열부, 센서, 제어기판의 라벨·기판 마킹을 별도로 촬영한다. 칩 기능은 식별한 정확한 번호의 제조사 데이터시트와 대조한다. 부품의 정격 W와 실제 운전 중 W도 분리한다.
3. **건조 결과와 전력량을 함께 측정:** 같은 직물·부하량·초기 수분·실온에서 코스별 시간, 누적 Wh, 종료 직물 무게와 건조도를 반복 기록한다. `WD25DB8995BZ`와 `DV17A9720BV`는 용량과 운전 형태가 다르므로 회당 Wh만 나란히 놓지 않는다. 부품별 Wh를 계산하려면 완제품 전력계 외에 회로별 계측이나 제조사 제어 로그가 필요하다.

삼성전자서비스에 확인할 때는 모델명만 제시하는 대신 **완제품 명판의 전체 모델 코드·제조번호·제조연월**을 함께 적고 아래 항목의 적용 부품번호와 대체 번호를 요청해야 한다.

| 모델 | 확인할 부품 | 현재 대조해야 할 번호 |
| --- | --- | --- |
| `WD25DB8995BZ` | 배수펌프 조립품과 하위 모터, 드럼 구동 모터, 송풍 팬, 컴프레서, 가열부, 메인/인버터 기판 | `DC97-24179B`·`DC31-00200A`가 해당 제조번호에 적용되는지 우선 확인. 해외 변형의 `DC93-00236G`·`DC31-00198A`는 국내 적용 여부를 별도로 질문 |
| `DV17A9720BV` | 컴프레서, 보조 히터, 드럼/송풍 모터, 메인/인버터 기판, 필터의 기본 구성 | `DC63-02526A`가 해당 제조번호의 기본 장착품인지 선택 소모품인지 확인 |

참고로 [한국소비자원 세탁건조기 비교시험](https://www.kca.go.kr/home/board/download.do?menukey=4002&fno=10045967&bid=00000013&did=1003812674)은 `WD25DB8995BB`를 3.6kg 표준 면 시험포·기본 표준코스로 시험했다. [국립전파연구원 인증](https://www.rra.go.kr/ko/license/A_b_popup_keyno.do?key_no=R-R-SEC-WD8000D)은 `BZ`를 기준모델, `BB`를 파생모델로 기재한다. 인증 관계만으로 시험 결과 또는 내부 부품이 같아지지는 않는다. [한국에너지공단 신고](https://eep.energy.or.kr/certification/certi_view_269.aspx?no=269210105)는 정확한 `DV17A9720BV`의 건조기 효율 지표를 제공하지만, 부품별 전력량이나 건조 완료 결과를 제공하지 않는다.

**현재 공개 가능한 분석 문장:** 두 모델의 제조사 사양으로 열관리 방식과 정격 전력을 설명하고, `WD25DB8995BZ` 관련 배수펌프는 부품표상의 후보임을 밝힐 수 있다. 특정 컴프레서·제어 반도체가 장착됐다거나 그 부품 때문에 어느 제품의 건조 성능 또는 전기요금이 우수하다는 주장은 아직 입증되지 않았다.
