실제 독자 재방문·달력 앱 점검 — 실행용 과제지
작성일: 2026-11-01
상태: 실제 사람의 응답·소요시간·성공률은 아직 수집하지 않았다. Google 캘린더 웹 가져오기는 별도 수행했고 google-calendar-import-validation.txt에 결과를 기록했다.

참여 조건
가전 구매 예정자, 집안 관리 담당자, 설치·수리 상담 경험자에게 각자 익숙한 기기로 수행을 요청한다.
에이전트 역할 평가는 사람의 응답으로 집계하지 않는다. 진행자가 화면의 정답 위치를 먼저 알려주지 않는다.
실명·연락처·주소·계약번호는 입력하지 않는다. 참가자 연락과 모집은 이 작업에서 수행하지 않았다.

과제1: 빠진 지출을 포함해 견적 비교하기
가상 LG WD523ACB 4년 자가관리, 월39900원, 등록0원,
렌탈 추가비228000원(설치·이전비 가정), 구매 추가비130000원을 넣는다.
어떤 항목을 합계에 넣었고 어떤 항목이 빠졌는지 본인의 말로 설명한다.
파일을 저장하고 화면을 닫은 뒤 다시 불러와 같은 조건이 복원되는지 확인한다.
관찰: 추가비를 월요금에 섞는가, 0과 미입력을 구분하는가, 해지 비용과 총기간 비용을 구분하는가.

과제2: 과거 측정 기록을 나중에 다시 이해하기
가상 냉장고, 2026-10-10→2026-10-17 같은 시각, 7일8.4kWh,
메모 '설정3도 / 실내24도 / 문 열림 보통'을 입력해 저장한다.
다음 방문에서 측정일과 기록일을 구분해 읽고, 이 기록으로 다시 입력해 메모를 수정한다.
원래 카드가 유지되고 수정본은 새로 저장해야 한다는 점을 확인한다.
관찰: 누적8.4와30일환산36.00의 의미를 구분하는가, 환경이 다른 값으로 절약 효과를 단정하는가.

과제3: 실제 달력 가져오기와 재가져오기
대상 앱: 사용자가 선택한 Google 캘린더. 아래는 실제 참가자가 반복 수행할 때의 과제이며 전용 테스트 캘린더로 범위를 한정한다.
WF24A9500KE 배수필터, 마지막관리2026-10-30의 ICS를 내려받는다.
기대: 2026-11-06 종일 일정, 종료는 다음 날, 설명서 원문·모델·조건 유지, 반복 일정 없음.
실제 앱이 임의 기본 알림을 붙이는지 확인한다. 파일에 알림이 없는 것과 앱에서 알림이 없는 것은 구분한다.
같은 파일을 다시 가져올 때와 새 파일을 내려받아 가져올 때를 구분해 중복/갱신 동작을 기록한다.
수첩의 관리일을 바꾸고 기존 달력 일정은 그대로인지 확인한다.
가져오기를 완료했다면 본인 테스트 일정만 식별해 정리한다. 다른 일정·공유자·알림을 변경하지 않는다.
실제 수행 전에는 앱별 성공·중복 방지·알림 동작을 완료로 표시하지 않는다.
