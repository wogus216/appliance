1. 설치 확인표 — 미지원 모델과 다른 조건
정수기 NOPE-1 주소: 모델이 미선택 상태이고 지원하지 않는다는 안내, 정확 모델을 목록에서 선택하라는 안내를 확인했다. 유사 모델로 자동 대입하지 않았다.
CTH10QBW: 실외기 오른쪽 원문 값600mm/300mm가 엇갈린다고 보여 주고 계산에 쓰지 않는다고 표시했다.
실외기 폭100cm 입력: mm 숫자 입력 오류를 표시했다. 단위를 자동 추측해 계산하지 않았다.
Qrevo Curv: 문턱40mm 입력 → 표준 문턱 안내30mm보다10mm 넘음을 계산했다. 복잡한 이중 문턱4cm와 표준3cm의 범위 설명도 붙었다.
발견(P1): 같은 결과의 상태 문구는 '기준보다 작음', 상단은 '기준보다 작은 칸이 있습니다'다. 상한을 넘은 상황과 공간이 부족한 상황을 같은 short 상태로 표현해 방향을 오해할 수 있다.
위치: src/components/tools/install-check-tool.tsx:36,179 및 src/lib/install-check.ts:308.
판정: 숫자 산술은 맞았지만 상한 초과의 상태 문구 수정이 필요하다.

2. 오류코드 → 상담 → 수리 비교
쿠쿠 E4 페이지의 상담 카드에 UNKNOWN-TEST/위험없음/가상증상을 입력했다.
결과는 '이 모델에 적용되는 조치는 확인하지 못했습니다', '설명서 적용 미확인'으로 나오고 특정 모델의 절차를 적용하지 않았다.
CDW-A0611TW/위험있음 선택 후 기록 생성: '재시작을 멈추고 점검을 요청하세요'로 바뀌었다. 안내 버전·공식 원문·사용자 입력의 구분도 기록에서 확인했다.
next-tools의 수리·교체 링크를 실제 클릭했다. 도착 주소는 /tools/repair-replace, 제품 모델 입력은 빈칸이었다.
발견(P2): 상담에서 확인한 모델·증상·진행 단계가 다음 도구로 이어지지 않는다. 사용자가 다시 입력하거나 두 기록을 따로 관리해야 한다.
참고: 첫 시도의 locator.getByRole 호출은 Aside가 지원하지 않아 도구 오류가 났다. 알려진 링크의 CSS로 다시 클릭해 위 결과를 확인했다. 사이트 결함으로 집계하지 않았다.

3. 수리·교체 — 다른 금액 상태
수리0원/교체120만원/보증적용 확인: 0원을 정상 입력으로 받고 차120만원을 표시했다. 포함 항목이 확인되지 않아 부분 비교로 남겼다.
수리-1원: 입력 오류로 바뀌며 기존 결과 금액은 숨겼다.
판정: 무상 수리·잘못된 입력 처리에서 실패를 관찰하지 못했다. 남은 수명/고장확률로 자동 경제성 결론을 내리지 않는 것은 명시된 기능 범위다.

4. 가전 수첩 — 실제 파일 왕복과 기록 보호
처음 수첩 저장 키가 없는 평가 주소임을 확인한 뒤 가상 WF24 관리1건+제품1건+구입일10/1+수리10/15/평가용 내용/25만원을 UI로 추가했다.
JSON을 실제 다운로드해 관리1/제품1/수리내역·금액을 읽었다. 다운로드 내용을 Aside 세션의 artifacts/recheck-notebook.json에 저장해 정식 setInputFiles로 업로드했다.
현재 관리 항목을2개로 늘린 뒤 파일을 선택했다. 확인 화면은 파일1/제품1, 현재2/제품1을 보여 주었다.
'취소': 현재 관리2개가 유지됐다.
다시 파일을 선택해 '이 파일로 바꾸기': 관리1/제품1, 구입일10/1, 수리내용/10/15/25만원이 복원됐다.
깨진 JSON 업로드: 'JSON 파일을 읽지 못했습니다' 표시. 그 뒤 평가용 관리/수리/제품 기록을 삭제하고 키가 처음처럼 없는 상태로 정리했다.
판정: 파일 보관·복원 기능은 실제로 쓸 수 있다. 불러오기는 합치기가 아닌 전체 교체이고 확인 화면이 이를 알린다. 자동 동기화·여러 기기의 동시 편집은 지원하지 않는다.

옛 평가표에서 갱신할 부분
- 정수기의 '입력 소실로 다시 비교 불편'은 선택적 파일 저장·복원으로 보완됐다. 자동 저장은 아니다.
- 일정표→수첩 재입력은 초안 전달로 해소됐다. 수첩의 추가 버튼은 사용자가 누른다.
- 전력은 기본 기록 모드와 추가 요금 가정을 분리했다. 계량기 필요·계절/설정/사용시간 영향은 그대로 남는다.
- 관리 일정의 자동 날짜 범위5모델9항목, 설치의 정확 모델 범위, 수리의 수명/고장률 미지원은 자료·기능 범위다. 임의의 수치로 채우지 않는다.

다음 우선순위
P1. 설치 결과에서 공간 부족과 문턱·높이차 등의 상한 초과 문구를 구분.
P2. 오류 상담→수리 비교→수첩에서 사용자가 원할 때 모델·상담 맥락을 이어 받기.
P2. 미지원 모델 방문자가 참고할 측정 방법·공식 원문·상담 질문의 대체 경로를 더 쉽게 찾게 하기.
운영 검증으로 남는 것: 실제 집에서 잰 값과 설치 상담 결과의 일치, 실제 사용자 입력 혼동, 관리 항목의 반복 사용·달력 앱 등록/알림, 장기간/다른 환경의 전력 측정 비교. UI 과제 완료와 이 효과를 구분해야 한다.

평가용 탭·서버를 정리했으며 기존 사용자 기록은 수정하지 않았다. 운영 배포는 하지 않았다.
