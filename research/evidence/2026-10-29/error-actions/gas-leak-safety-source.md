# 가스 냄새가 날 때 행동 요령 — 한국가스안전공사 원문 확인 — 2026-10-29

보일러 사용자용 짧은 안내에 쓸 근거다. 가스안전공사(kgs.or.kr) 원문만 근거로 삼았고, 블로그·뉴스·지자체 재게시 문구는 보지 않았다. 귀뚜라미 97 문구는 비교용으로만 적었다.

- **분석 단위**: 공사 원문 한 곳에서 가정 사용자가 가스 누출을 알았을 때 할 행동을 적은 항목 1개다.
- **모집단**: kgs.or.kr `가스와생활 > 국민행동요령` 메뉴의 하위 페이지 5개(abaa·abab·abad·abae·abaf)와, 그 페이지에 링크된 한국어 PDF 2개(`foreigner_safety_guide_kor.pdf`, `foreigner_safety_trick_kor.pdf`)다. 메뉴는 홈(https://www.kgs.or.kr/) HTML의 GNB에서 읽었다.
- **확인일**: 2026-10-29 14:53~14:55 KST, `curl -A "<Chrome UA>"`로 받았다. 모든 페이지가 HTTP 200이었고 서버 렌더라 브라우저는 쓰지 않았다.
- **받은 파일**: `scratchpad/gas-safety/`(저장소 밖). 본문 추출 스크립트는 `scratchpad/gas-safety-scripts/extract.py`에 따로 두었다.
- **인용 검증**: 이 문서의 「」 인용 54건을 원문 추출 텍스트와 대조했다. 공백은 무시하고 부분일치로 봤고, 불일치는 0건이었다. 원문 추출 텍스트는 HTML 본문, PDF `pdftotext`, krb.co.kr/self/352, boilers.json이다. alt 속성 1건은 원본 HTML에서 대조했다. 대조군도 돌렸다. 원문에 없는 문장(「가스 냄새가 나면 휴대전화를 쓰지 마세요」)은 불일치로 잡혔고, 원문에 있는 문장은 일치로 잡혔다.

## 못 한 것·찾지 못한 것

- **실내 전화·휴대전화를 쓰지 말라는 문구: 공사 원문에서 찾지 못함.** 위 7개 문서 추출 텍스트에서 「전화」는 0건이었다. 「휴대」는 「휴대용 가스레인지」 1건뿐이다. 대조군으로 「환풍기」를 같은 방식으로 찾았고 abaa·abad에서 1건씩 잡혔다. 「외부 전화로 연락」과 「주위의 전화를 이용하는 행위」 금지는 귀뚜라미 원문에만 있다(아래 비교표).
- **건물 밖으로 대피하라는 지시: 가정용 항목에는 없음.** abad의 「대피」 6건은 모두 독성가스 상자, 저장탱크, 정압기, 용기 화재처럼 시설 쪽 항목에 있다. 가정 항목에는 「이웃에 알려서 도움을 받고」만 있다.
- **도시가스사·LPG 판매점의 개별 전화번호: 원문에 없음.** 원문은 「도시가스 지역관리소」와 「LPG 판매점」에 연락하라고만 한다.
- **HTML 페이지의 게시일·수정일: 불명.** 페이지에 날짜 표기가 없고, 응답 헤더에 `Last-Modified`도 없었다.
- **119와 1544-4500은 PDF(2017년 제작)에만 있다.** 현행 HTML 누출 페이지에는 전화번호가 없다. 대조군으로 같은 정규식을 홈 HTML에 돌렸고, 푸터의 「Tel. 1544-4500」이 잡혔다. 그러니 HTML 누출 페이지에 번호가 없는 것은 도구 문제가 아니다.
- 읽지 않은 것: `oldman.pdf`(어르신을 위한 가스안전 사용요령)는 이미지 PDF(2010년, 텍스트 8자)라 열어 보지 않았다. `selfCheckSkill.pdf`, 영어 등 다른 언어 PDF, cyber.kgs.or.kr 민원신고 페이지도 보지 않았다.

## 6. 응답 해시

HTML은 같은 URL을 두 번 받으면 원본 해시가 달랐다(abad 1차 `7cd85d16…`, 2차 `76e28a52…`). 추출 본문 해시는 두 번 모두 같았다. 그래서 아래 해시는 **추출 본문 기준**이다.

추출 규칙은 다음과 같다.

1. `<section id="content"` 부터 `<div class="survey-box">` 앞까지 자른다.
2. script·style을 지우고, `<br>`과 블록 닫는 태그를 줄바꿈으로 바꾼 뒤 나머지 태그를 지운다.
3. HTML 엔티티를 디코드하고, 줄마다 공백을 하나로 접고, 빈 줄을 버린다.
4. `\n`으로 이어 붙인 UTF-8의 sha256을 구한다.
