# 세탁기·건조기·정수기 설치 조건 원문 확인

확인일: 2026-10-29. 설치 확인 도구를 세탁기·건조기·정수기로 넓히기 위해 6개 정확 모델의 공식 설명서를 다시 받아 설치 조건을 뽑았다. 구조화한 값은 같은 폴더의 `washer-dryer-purifier.json`에 있다.

- 수집: `curl`(브라우저 UA)로 6개 원문을 받았고 모두 HTTP 200이었다. 삼성·LG·코웨이 PDF는 `pdftotext -layout`으로 읽었다. 치수가 든 쪽(삼성 건조기 13·87쪽)과 라벨 글꼴이 깨진 쪽(삼성 콤보 18·24쪽), 삼성 세탁기 11쪽 도면은 이미지로 직접 대조했다. SK매직은 HTML을 텍스트로 바꾸고 치수도와 설치 그림 7장을 이미지로 확인했다.
- 받은 파일 6개의 SHA-256은 10-27·10-28 기록과 모두 같다. 10-28 이후 원문은 바뀌지 않았다.
- 기준: 값은 그 모델 열 또는 모델 구분이 없는 공용 본문에서만 옮겼다. 다른 열의 값(예: 건조기 19·20 kg, 코웨이 CPI-7400N, SK A500C·A600C)은 옮기지 않았다. 원문에 없는 수치는 `unverified`로 두었다. 고장 진단 절에만 있는 수치는 `confirmed`로 두되 `where`에 절 이름을 적었다.
- 카탈로그 대조: `techSpecs.dimensions` 문자열의 순서는 폭×높이×깊이다(`src/lib/__tests__/fridge-fit.test.ts:83`). 5개 모델은 설명서와 같다. SK매직은 카탈로그에 dimensions 필드가 없어 대조하지 못했다.
