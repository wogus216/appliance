# LG 정수기 필터 AGM 판매 품번과 QF 라벨 코드 대조 — 2026-10-01

LG 공식몰의 소모품 상세 페이지에서 **판매 품번, 첫 번째 제품 사진의 카트리지 라벨, 적용 본체 모델**을 한 페이지씩 대조했다. 웹 검색 결과나 판매점의 호환 표시는 코드 대응 근거로 사용하지 않았다.

| LG 공식몰 판매 품번 | 공식 페이지의 첫 번째 제품 사진에 보이는 필터 모델명 | 같은 페이지의 사용 가능 모델 |
| --- | --- | --- |
| [중금속9 흡착 필터 `AGM30040101`](https://www.lge.co.kr/care-accessories/water-purifier/agm30040101) | [LG 제공 확대 사진](https://www.lge.co.kr/kr/images/care-accessories/water-purifier/md09043828/gallery/large01.jpg)의 실물 라벨에 **`QF0422L`** | **`WD523ACB.AKOR`** 포함 |
| [바이러스 클리어 필터 `AGM30063801`](https://www.lge.co.kr/care-accessories/water-purifier/agm30063801) | [LG 제공 확대 사진](https://www.lge.co.kr/kr/images/care-accessories/water-purifier/md09830826/gallery/large01.jpg)의 실물 라벨에 **`QF1122L`** | **`WD523ACB.AKOR`** 포함 |

따라서 **LG 공식 상품 페이지가 판매 품번 `AGM30040101`·`AGM30063801`을 사진 속 `QF0422L`·`QF1122L` 카트리지와 연결**한다는 근거를 확보했다. 두 QF 코드는 [WQA `All-Puri Filter System`의 교체 요소 목록](https://find.wqa.org/find-products/ctl/detail/mid/1054/cid/lg_electronics/sid/63?keyword=lg+electronics)과 [미래소비자행동의 독립 필터 시험](https://can.or.kr/board/view.php?boardinfo_idx=201&idx=1278)에 적힌 코드와 일치한다.

**적용 범위:** 이는 LG의 현재 상품 사진과 적용 모델 목록을 통한 **부품 식별 연결**이다. 사진이 모든 생산 시기·납품 배치의 카트리지 구성을 보증하거나 소비자단체가 `WD523ACB` 완제품을 시험했다는 뜻은 아니다. 소비자단체의 색도·탁도·클로로포름·대장균 결과는 **표시된 QF 필터 세트의 시험값**으로 인용한다. [국내 품질검사 목록](./kwtc-exact-water-purifier-register.md)의 `WD523ACB` **1,500 L**, WQA 필터 시스템의 **200 US gal**, 소비자단체 시험의 **2,000 L**는 서로 다른 범위와 조건으로 유지한다.

## 사진 라벨의 105갤런 표기 범위

두 제품 사진의 라벨에는 **`NSF 인증 Capacity: 105 Gallons`**와 시스템 모델 **`ADQ74793704`**가 함께 인쇄되어 있다. [LG의 얼음정수 냉장고 제품 설명](https://www.lge.co.kr/product/object-collection/j825gcb442?modelId=MD10449855&pdpType=PURCHASE)은 **`ADQ74793704` 3단 정수필터**의 NSF/ANSI 42·53·401 시험 범위를 **397 L(105 US gal)**로 설명한다. 이 페이지는 **냉장고의 3단 필터 시스템**을 설명하며 `WD523ACB`의 시험 자료가 아니다.

반면 [WQA 목록](https://find.wqa.org/find-products/ctl/detail/mid/1054/cid/lg_electronics/sid/63?keyword=lg+electronics)의 **`All-Puri Filter System`은 `QF0422L`·`QF1122L` 교체 요소와 200 US gal**을 표시한다. 따라서 105갤런과 200갤런은 **서로 다른 이름·구성의 시스템에 붙은 표시**로 취급한다. 두 카트리지의 코드가 겹친다고 해서 두 시스템의 인증 용량을 교환하거나 `WD523ACB`의 국내 유효정수량 1,500 L를 대체하지 않는다. NSF의 현재 공개 검색에서 `ADQ74793704` 정확한 모델 결과는 확인되지 않아 현재 인증 유효 상태도 단정하지 않는다.
