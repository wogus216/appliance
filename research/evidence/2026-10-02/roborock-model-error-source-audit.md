# 로보락 S8 Pro Ultra·Qrevo Curv 코드 대조 — 2026-10-02

정확한 모델의 공식 [S8 Pro Ultra 문제 해결](https://help.roborock.com/us/product/s8-pro-ultra-message?category=troubleshooting), [Qrevo Curv 문제 해결](https://help.roborock.com/us/product/roborock-qrevo-curv-message?category=troubleshooting) 페이지와 두 모델의 [S8 Pro Ultra 설명서](https://support.roborock.com/hc/en-us/articles/17819473954201-Roborock-S8-Pro-Ultra-CE-User-Manual-EN-FR-DE-IT-ES-PL-NO-SE), [Qrevo Curv 설명서](https://support.roborock.com/hc/en-us/articles/46138541909529-Roborock-Qrevo-Curv-CE-EN-DE-ES-FI-FR-HL-IT-NO-PL-PT-SE-DK-RO-User-Manual)를 열어 대조했다. 고객지원 페이지는 미국 지역 문서이며 국내 판매형의 모든 펌웨어 표기를 보장하지 않는다.

| 모델 | 공식 고객지원에서 확인한 코드 | 게시 판단 |
| --- | --- | --- |
| S8 Pro Ultra | Error 1(레이저 회전), 4(낙하 방지 센서), 5(메인브러시), 9(필터 측면 자석), 13(충전 접점) | 이 다섯 개를 남기고 Error 2·3·12는 정확한 모델의 근거가 없어 제거. Error 9는 기존 먼지통/필터 재장착 추측 대신 공식 필터 자석 점검으로 수정. |
| Qrevo Curv | Error 1·4·5·13 | 네 개를 남기고 Error 15(물걸레 모듈)·21(물탱크)는 정확한 모델의 근거가 없어 제거. |

두 모델 설명서에는 번호별 오류 대조표가 없다. 다른 [로보락 S7 공식 설명서](https://support.roborock.com/hc/en-us/article_attachments/900008254623)는 Error 15를 벽면 센서로, [S7 MaxV 공식 설명서](https://support.roborock.com/hc/en-us/article_attachments/6287880640281)는 Error 21을 수직 범퍼로 설명한다. 이 뜻을 Qrevo Curv에 옮기지는 않았지만, 기존의 물걸레·물탱크 진단이 공통 번호 체계라고 가정할 수 없음을 보여 준다. 제거는 해당 번호가 Qrevo Curv에서 절대 나타나지 않는다는 뜻이 아니다.

[로보락 코리아 Qrevo Curv 제품 설명](https://kr.roborock.com/pages/roborock-qrevo-curv)은 DuoDivide를 **메인 브러시**로, 물걸레는 별도 듀얼 회전 방식으로 설명한다. 본체 치수는 352 × 347 × 103mm이며 단일 문턱 최대 3cm, 이중 문턱 최대 4cm를 구분한다. [모델 설명서](https://support.roborock.com/hc/en-us/article_attachments/46138473099289)는 도크 설치 공간을 높이 0.9m·폭 0.46m·앞쪽 깊이 1.2m 이상으로 안내한다. 제품 페이지의 기존 DuoDivide 물걸레 표기, 79.8mm 높이, 모든 4cm 문턱 통과처럼 읽힐 문구를 이에 맞춰 수정했다.

같은 국내 제품 페이지는 기본형 도크 사양 뒤에 **Qrevo Curv + 물통 채움 및 배수 시스템**을 별도 구성으로 소개한다. 자동 급배수와 세제 디스펜서는 이 별도 구성의 항목이므로 기본형의 포함 기능으로 쓰지 않는다. 75℃는 도크의 걸레 세척수 온도이며 바닥 세정수 온도가 아니다. 기본형 도크 치수는 450 × 450 × 450mm다. [S8 Pro Ultra 제조사 사양](https://de.roborock.com/products/roborock-s8-pro-ultra)에서 6000Pa, VibraRise 2.0, Reactive 3D와 도크의 먼지비움·걸레 세척·건조를 대조했다. S8의 20~30mm 문턱 통과와 두 모델의 필터 E11 등급은 정확한 모델 출처로 확인하지 못해 게시 문구에서 제거했다.
