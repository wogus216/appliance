# SK매직 DWA-81R0D `dr` 표시 범위 검수 — 2026-10-02

- [DWA-81R0D를 명시한 SK매직 공식 공용 설명서](https://m.manual.skmagic.com/2019/model/DWA/DWA81R0D00SL/Manual.htm): 제품규격에 해당 모델이 직접 표기된다. 「고장 신고 전 확인하기」에는 작동하지 않을 때 문이 완전히 닫혔는지 확인하라고 하지만, HTML 본문과 「자가 진단하기」에서 `dr` 표시·도어 리셋 절차는 확인되지 않는다. 설명서에는 F1·F5 표시는 문자로 명시된다.
- [SK인텔릭스서비스 식기세척기 FAQ](https://www.skintellixservice.com/web/easy/easyMain.do?selectedPrdCd=04&selectedSubPrdCd=DWA&tabIndex=0): 이전 코드 대조의 공식 서비스 근거. `dr`의 DWA-81R0D 적용은 확인하지 못했다.
- 다른 [DWA19R0P 공식 설명서](https://m.manual.skmagic.com/2019/model/DWA/DWA19R0P00BL/Manual.htm)에는 문을 닫으면 `dr` 표시가 사라진다는 문구가 있다. 이는 해당 모델의 근거일 뿐, DWA-81R0D의 코드로 이식할 수 없다.

따라서 공개 DWA-81R0D 제품과 SK매직 오류 허브에서 `dr` 항목을 제거했다. 문이 닫혔는지 확인하는 일반 점검은 유효하지만, 30초 전원 재연결로 도어를 리셋한다거나 잠금 스위치 고장이라는 단정은 공식 DWA-81R0D 설명서에서 확인되지 않는다.
