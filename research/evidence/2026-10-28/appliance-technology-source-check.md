# 식기세척기·건조기·로봇청소기 기술·관리 근거 대조

확인일: 2026-10-28. 기존 정수기 지도와 다른 세 품목의 정확 모델을 대상으로 공식 자료를 다시 확인했다. 임의의 내부 구조·순환 순서를 그리지 않고 확인한 부품과 관리 영역을 묶는다.

## 쿠쿠 CDW-A0611TW

[공식 공용 설명서](https://www.cuckoo.co.kr/upload_cuckoo/_bo_rep/manual/200424%3Dz0383-0082a0%20rev.1_cdw-a0611t.pdf)를 재수신했다. 한글 텍스트 추출이 되지 않아 인쇄 18·22·23·24쪽을 이미지로 읽었다. PDF 쪽 번호와 인쇄 번호는 같다.

- 18쪽: 식기 겹침 방지, 안쪽이 분사기 쪽을 향하게 배치, 큰 찌꺼기 제거, 작은 식기·수저가 노즐 회전을 막지 않도록 주의.
- 22~23쪽: 프리·마이크로·스테인리스 필터, 분리·세척·재조립 안내. 필터 없이 사용 금지. 정기 청소는 안내하지만 고정 일수는 제시하지 않는다.
- 24쪽: 노즐 구멍 막힘 점검, 필요 시 분리·세척·회전 확인. 매번 사용 후 급수 중지와 문을 열어 내부를 말리는 관리 안내.
- 24쪽: 청소 전 플러그 분리, 동작 직후 내부가 식은 뒤 청소. 자동 문 열림 기능으로 표시하지 않는다.

## 삼성 DV17A9720BV

[정확 모델의 공식 지원·사양](https://www.samsung.com/sec/support/model/DV17A9720BV/)과 연결된 [공용 사용설명서](https://downloadcenter.samsung.com/content/UM/202504/20250401094234705/WM0013_IB_DV8700TK_DV19A9740_KO_250313.pdf)를 확인했다. PDF를 재수신하고 `pdftotext -layout`으로 대조했다. PDF 65쪽이 인쇄 65쪽임도 확인했다.

- 지원 페이지 기본 사양: 건조 방식은 인버터 히트펌프 + 히터. 외관 사양: 내장형 물통 7L, 마이크로 안심필터 있음.
- 인쇄 13~14·65쪽: 물통과 배수호스 설치, 물통 사용 시 매번 비우기, 양손으로 수평을 유지하는 취급 안내. 물통 관리는 직배수 설치 상태와 구별한다.
- 인쇄 66~68쪽: 일반 필터는 매회 청소. 내부·외부 필터, 물 세척했다면 완전 건조 후 조립.
- 인쇄 76~77쪽: 열교환기 청소 표시·먼지 확인과 청소 절차. 날카로운 핀을 맨손으로 만지거나 변형시키지 않도록 주의.
- 인쇄 78~79쪽: 사용 중인 3차 필터는 25회마다 청소. 알림은 3차필터알림 설정 시 발생. 이때 열교환기도 확인. 일반 필터의 매회 기준과 합치지 않는다.
- 정확한 냉매 회로·부품별 가동 시간·절전율은 이 자료로 확인하지 않아 표시하지 않는다. 열교환기 자동 청소 기능으로 설명하지 않는다.

## 로보락 S8 Pro Ultra

[공식 영문 설명서](https://support.roborock.com/hc/en-us/article_attachments/18342044174873)를 재수신했다. 다국어 PDF의 영문 3~14쪽을 `pdftotext -layout`으로 대조했다. PDF 11쪽이 영문 11쪽이다. 국내 동봉 설명서가 다르면 해당 안내를 우선한다는 범위를 화면에 표시한다. 국내 전원 규격 등의 수치로 확장하지 않는다.

- 영문 5~6쪽 A4·A6·A10: 본체 먼지 필터, 분리 불가인 물걸레 홀더와 분리되는 걸레, 도크의 청수·오수통 및 물 필터를 구별한다.
- 10쪽 C1: 메인 브러시 2주마다 청소·6~12개월 교체.
- 11쪽 C6: 본체 세척 가능 필터 2주마다 청소·6~12개월 교체. 표면을 손·브러시·단단한 물체로 문지르지 않으며 세척 후 24시간 충분히 건조.
- 11쪽 C7: 물걸레 필요 시 세척·3~6개월 교체. 세척 후 자연 건조.
- 11쪽 C10~C11, 14쪽: 도크 이동 시 물통을 제거하고 지정한 곳을 잡기. 오수통 필요 시 청소, 청수 보충·오수 비움 및 장착 확인.
- 11쪽 C13: 도크 물 필터는 필요 시 청소. 본체 공기 필터의 주기를 이 부품에 옮기지 않는다.
- 12쪽 C14: 일회용 먼지봉투가 가득 차면 교체. 고정 사용 일수는 만들지 않는다.
- 3·7쪽: 청소·관리 전 전원 차단·플러그 분리, 도크를 젖은 천으로 닦지 않는 등 부품별 허용 방법을 확인한다.

## 적용 범위

세 모델만 `src/lib/data/appliance-technology.ts`에 등록한다. CDW-A0611TS·대용량 식기세척기, 다른 DV 모델, S8 계열·다른 급배수 도크에 자동 확장하지 않는다. 기존 CHPI-7400N 정수기는 기존 물길·전력 도식을 유지한다.

연결도는 기능별 관리 영역이다. 세척력·흡입 청소율·월 전기요금·부품 잔여 수명을 계산하지 않으며, 관리 체크도 실제 작업 완료나 성능 판정으로 표현하지 않는다.
