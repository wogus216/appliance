# 구매 가이드 배치 예상안

2026-11-03: 이 예상안을 실제 `/category/dishwasher`에 반영했다. 현재 확인 주소는 http://127.0.0.1:3012/category/dishwasher 이다. 아래 비교 시안은 반영 전 작업 기록이며 더 이상 재생성하지 않는다.

사용자가 개선 방향을 화면으로 먼저 보고 싶다고 요청하여 식기세척기 가이드1편을 대표 시안으로 만들었다.

- 비교: 현재 구성 / 개선 예상안. 데스크톱 / 모바일 너비 전환.
- 예상안: 제품 사진2장 → 선택 기준표 → 조리대·열린 문·통로 개념도 → 확인 순서 → 기존 설치 도구·상세 근거.
- 기존 폰트·색·제품 목록·원고를 유지한다. 새로운 가격·치수·설치 허가를 추가하지 않았다.
- 비교 페이지와 가이드 배치는 정적 시안이다. 원본 사이트의 검색·메뉴를 구현한 기능 시안은 아니다.
- 실제 식기세척기 가이드의 배치는 아직 바꾸지 않았다. 미리보기에는 광고·hydration 스크립트를 제거하고 noindex를 넣었다.

## 열기

기존 out/ 정적 빌드와 3012 프리뷰 서버를 이용한다.

```sh
python3 research/previews/reading-layout/build.py
```

http://127.0.0.1:3012/__preview/reading-layout/index.html

일반 Next 빌드는 out/의 시안을 지운다. 필요하면 위 명령으로 다시 만든다. 앱 라우트·사이트맵·메뉴에 시안을 추가하지 않았다.
