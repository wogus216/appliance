# 공개 범위 축소 전 구현 — 2026-11-19

에러코드와 수리·관리에 집중하기 위해 구매 카탈로그·브랜드·카테고리·조합 비교·소재 사전과 구매/설치/전력 도구의 라우트를 옮겼다. 이 폴더는 Next.js의 app 디렉터리가 아니며 빌드·공개 대상이 아니다. 원자료는 기존 관리 도구의 근거와 과거 기록으로 보관한다.

퇴역한 공개 화면만 검증하던 테스트도 같은 경로에 보관한다. 현재 공개 범위·링크·핵심 기능 검사는 src/ 안에서 계속 실행한다. 복원할 때는 현행 공개 범위와 일치시키고 링크·사이트맵을 다시 검증해야 한다.
